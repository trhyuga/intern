# NEON VANGUARD — testtriumph

ネオンベクター縦スクロールシューティング。単一の `index.html` だけで動きます
（HTML + CSS + Vanilla JS + Canvas 2D、ビルド不要・外部ライブラリなし）。
BGM のみ `bgm/` フォルダの mp3 を参照します。

- プレイ: https://intern-xi-lilac.vercel.app/intern2026/testtriumph/
- 完成版 v1.0（凍結・ロールバック用）: https://intern-xi-lilac.vercel.app/intern2026/testtriumph/v1.0/

---

## ロールバック手順

`v1.0/index.html` は **v1.0 完成時点をそのまま凍結したコピー** です。
何かおかしくなったら、次のどちらかで確実に戻せます。

### 方法A: 凍結コピーを上書きする（GitHub のブラウザ操作だけで完結）

1. `intern2026/testtriumph/v1.0/index.html` を開く
2. 右上の **Download raw file** でダウンロード
3. ダウンロードしたファイルを `index.html` にリネーム
4. ファイル内の `'../bgm/` を `'bgm/` に一括置換（5か所）
   ※ v1.0 は1階層下にあるため BGM パスだけが異なります
5. `intern2026/testtriumph/` で **Add file → Upload files** して上書きコミット

### 方法B: タグから戻す

リリースタグ **`v1.0`** が v1.0 完成コミットを指しています。

1. リポジトリの **Releases** から `v1.0` を開く
2. **Source code (zip)** をダウンロード
3. 中の `intern2026/testtriumph/index.html` を取り出して、
   `intern2026/testtriumph/` に **Upload files** で上書きコミット

### 方法C: コミット履歴から戻す（1つ前に戻すだけなら最短）

1. `index.html` の **History** を開く
2. 戻したいコミットの **View file** → **Download raw file**
3. `intern2026/testtriumph/` に Upload files で上書き

いずれの場合も、コミットすると Vercel が自動で再デプロイします
（1〜2分。反映を確認したい時は URL の末尾に `?v=999` のような
クエリを付けてキャッシュを避けてください）。

## v1.0 の内容

### 基本仕様

| 項目 | 内容 |
|---|---|
| 画面 | 論理解像度 480×800 / DPR対応スケーリング |
| 操作 | 相対ドラッグ移動（マルチタッチ対応）／キーボード（矢印・WASD・B・P） |
| セーブ | localStorage キー `neon_vanguard_save_v1` |
| ステージ | 3ステージ（各ステージに中ボス＋ボス）＋大ボス |
| 敵 | ザコ13機種／中ボス3体／ステージボス3体／大ボス1体 |
| 所要時間 | 死に戻りで強化しながら約30分でクリア |

### 強化項目（全9種）

| 項目 | 最大Lv | 内容 |
|---|---|---|
| メインショット | 6 | 単発 → 2連射 → 3/5/7/9way扇 → 11way大扇★ |
| 連射速度 | 5 | 発射間隔 210ms → 78ms（毎秒4.8発 → 12.8発） |
| 火力 | 6 (+1) | 1発 9 → 55ダメージ（限界突破で75） |
| 僚機ウイングマン | 2 | 1機=本体の60%威力 / 2機=貫通ビーム（僚機弾の1.1倍） |
| 装甲(最大HP) | 5 | 最大HP 100 → 300 |
| シールド | 3 (+1) | バリア40〜160 / 被弾後の自動回復（Lv1は極遅） |
| ボム所持数 | 3 | 全画面130 / ボス240ダメージ |
| ホーミング | 3 (+1) | 1.5秒ごとに追尾ミサイル、1発 本体火力の1.4倍 |
| クレジット獲得 | 4 | +20% 〜 +80% |

全項目カンストまで約73,000c（限界突破ぶんを含む）。

### 機体形式（攻撃系の強化度で5段階に進化）

`メインショット×2 ＋ 火力 ＋ 連射` の合計値で決まります。

| 形式 | 条件(合計) | 見た目の変化 |
|---|---|---|
| MK-I FALCON | 0〜2 | 基本形 |
| MK-II RAPTOR | 3〜7 | 主翼延長＋翼端キャノン |
| MK-III LANCER | 8〜12 | 前進カナード＋4発エンジン |
| MK-IV CRUSADER | 13〜18 | 副翼＋背びれ＋背骨ライン |
| MK-V SOVEREIGN | 19〜 | 機首ブレード＋翼端オーブ |

### オーバードライブ

| 段階 | 条件 | 効果 |
|---|---|---|
| OVERDRIVE | フル強化でラスボス戦に突入 | 火力・シールド +30% |
| 限界突破 | フル強化でラスボスに敗北すると解放 | 火力・ホーミング・シールドの上限+1 |
| OVERDRIVE+ | 限界突破ぶんもカンスト | 火力・シールド +40% |
| 常時オーバードライブ | 上記＋ ◈100,000c で購入 | ステージ1から金色形態で出撃 |

### クリアランク

| ランク | 条件 | エンドロール | FIN |
|---|---|---|---|
| **Z** | 常時オーバードライブ＋フル強化で大ボス撃破 | あり（約40秒・スキップ可） | あり |
| **S** | OVERDRIVE+ の状態で撃破 | なし | なし |
| **A** | OVERDRIVE の状態で撃破 | なし | なし |
| **B** | 通常形態で撃破 かつ 50,000点以上 | なし | なし |

## コードを読む人へ

`index.html` は約4,000行あり、日本語コメントでセクション分割しています。

- 音まわり: `Sound`（WebAudioの簡易シンセ）／ `Music`（mp3再生）
- 強化定義: `UPGRADES` — `desc()` がショップ用、`spec()` がエンドロール用
- 数値の出どころ: `fireIntervalAt()` `dmgAt()` `SHIELD_DELAY` `SHIELD_REGEN`
  （実際の戦闘処理と表示が同じ式を参照しています）
- 敵: `ENEMY_DEF` / `updateEnemy()` / `drawEnemy()`
- ボス: `makeBoss()` / `bossPatterns()` / `updateBoss()` / `drawBoss()`
- 自機描画: `drawShipBody()`（形式MK-I〜Vの分岐もここ）
- 画面遷移: `Game.state` と `STATE` 定数、描画は `loop()` の switch

描画負荷が高い端末では `GLOWQ` が自動的に下がり、発光のぼかしを弱めて
フレームレートを優先します（`loop()` 内で調整）。
