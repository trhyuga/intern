# G1 PREDICTOR — internS

年間のG1をすべて予想して賭ける、競馬予想ゲーム（**初期設定版・雛形**）。
単一の `index.html` だけで動きます（HTML + CSS + Vanilla JS + Canvas 2D、ビルド不要・外部ライブラリなし）。

- プレイ（main に反映後）: https://intern-xi-lilac.vercel.app/intern2026/202610/internS/

> レース名・馬名はすべて**架空**です。本物のG1名に差し替える場合は、
> 最新のJRA開催日程を確認してから `CALENDAR` を書き換えてください。

---

## ゲームの流れ

```
タイトル → 競馬新聞 ⇄ パドック → 馬券購入 → レース（自動） → 結果 → 次のレース …
                                                         └ 所持金が100円未満 → GAME OVER
                                    全G1を終えたら SEASON CLEAR → 翌年も続ける（ループ）
```

| 画面 | 内容 |
|---|---|
| 競馬新聞 | 8頭立ての出走表。記者3人の印（◎○▲△）、脚質、前走着順、距離適性、単勝オッズ |
| パドック | 馬が周回するアニメと「気配」コメント。**当日の調子（隠しパラメータ）のヒント** |
| 馬券購入 | 単勝・馬連。100円単位、複数枚まとめ買い可、見送りも可 |
| レース | 自動で走る。**序盤 → 中盤 → ラストスパート**で画面（カメラ）が切り替わり、実況が文字で流れる |
| 結果 | 1着・2着・3着と払い戻し |

## 基本仕様（初期値）

| 項目 | 値 | 場所 |
|---|---|---|
| 元手 | 10,000円 | `CONFIG.START_MONEY` |
| 頭数 | 8頭（1枠1頭） | `CONFIG.FIELD` |
| 年間G1 | 24戦（架空） | `CALENDAR` |
| 控除率（仮） | 単勝 20% / 馬連 22.5% | `CONFIG.TAKEOUT_*` |
| レース演出の長さ | 約36秒（スキップ可） | `CONFIG.RACE_SECONDS` |
| セーブ | localStorage `internS_g1predictor_save_v1` | `Save` |

### 予想の要素（どこに「読み」があるか）

| 要素 | 新聞で見える | 効き方 |
|---|---|---|
| スピード・スタミナ・末脚 | 印・前走着順にぼんやり反映 | 基本の速さ / 長距離の失速 / 直線の伸び |
| 脚質（逃げ・先行・差し・追込） | ○ | 序盤は前が有利、ラストは後ろが伸びる |
| 距離適性 | ○（◎○△） | 得意距離から離れるほど遅い |
| 当日の調子 | **×（パドックでだけヒント）** | オッズには反映されない ＝ 穴を見つける手がかり |
| 運 | × | レースごとのブレ |

オッズは「調子を知らない世間」の目線で400回シミュレーションして作っています。
パドックで好調な馬を見抜けると、オッズより勝ちやすい＝儲けのチャンス、という設計です。

調整前の実測（3年分×24戦×20回）: 全頭に単勝を買い続けた回収率 約82〜89%、
1番人気の勝率 約22〜25%。

## 調整するときに触る場所

`index.html` 内（日本語コメントで区切っています）:

- `CONFIG` — 元手・控除率・演出の長さなど
- `CALENDAR` — G1の名前・月・芝/ダート・距離
- `SIM` — 能力差と運のバランス。`LUCK` を上げると荒れる、`SPEED_W` を上げると堅くなる
- `simulate()` — レースの物理（脚質・スタミナ・適性・調子）
- `computeOdds()` — オッズの作り方
- `paddockComment()` — パドックのコメント
- `commentPhase()` / `commentEvents()` — 実況の文言
- `drawRace()` / `drawOverhead()` — レース画面（序盤＝横から引き、中盤＝俯瞰、ラスト＝寄り）
