# G1 PREDICTOR — internS

年間のG1をすべて予想して賭ける、競馬予想ゲーム（**初期設定版・雛形**）。
単一の `index.html` だけで動きます（HTML + CSS + Vanilla JS + Canvas 2D、ビルド不要・外部ライブラリなし）。

- プレイ（main に反映後）: https://intern-xi-lilac.vercel.app/intern2026/202610/internS/

> レース名は **JRAの平地G1（全24戦）** を2026年の日程順に並べています。
> 出走馬は **歴代の名馬**（牝馬限定戦は歴代の名牝）から、レースの条件に合う馬が選ばれます。
> ゲーム画面では「歴代の名馬」とは書かず、普通の出走馬として出します。
> 騎手の名前・写真、JRAなどのロゴは使いません。
> 脚質・得意距離・芝/ダートは実際の戦績に寄せたおおよその設定で、能力値はゲーム用の目安です。
> 2歳戦・3歳戦の年齢制限は「時代を超えた夢のレース」として無視しています。
> 年が変わったら、JRAの開催日程を確認して `CALENDAR` を見直してください。

## ゲームの流れ

```
タイトル → 競馬新聞 ⇄ パドック → 馬券購入 → レース（自動） → 結果 → 次のレース …
                                                         └ 所持金が100円未満 → GAME OVER
                                    全G1を終えたら SEASON CLEAR → 翌年も続ける（ループ）
```

| 画面 | 内容 |
|---|---|
| 競馬新聞 | 8頭立ての出走表。記者3人の印（◎○▲△）、脚質、前走着順、距離適性、単勝オッズ |
| パドック | 馬が周回するアニメと「気配」コメント。**当日の調子（隠しパラメータ）のヒント** |
| 馬券購入 | 単勝・複勝（3着以内）・馬連・3連単（着順どおり）。100円単位、複数枚まとめ買い可、見送りも可 |
| レース | 発走前にそのG1の特徴を紹介。自動で走り、**序盤 → 中盤 → ラストスパート**で画面（カメラ）が切り替わり、実況が文字で流れる。的中すると紙吹雪の演出 |
| 結果 | 1着・2着・3着と払い戻し |
| エンディングロール | 24戦を終えると、優勝馬・レースごとの収支・年間成績が流れる |
| 年間成績 | タイトルの「年間成績を見る」から全シーズンを見返せる（localStorage `internS_g1predictor_records_v1`。はじめからやり直しても残る） |
| 大的中 | オッズ10倍以上の的中で金色の演出とファンファーレ（WebAudio）。通常の的中はチャイム |
| 効果音 | 発走前のオリジナルファンファーレ、ゲートが開く音、歓声（発走・ゴール）。右上の「音 ON/OFF」で消せる |
| 視点の切り替え | 発走後、右上の小窓にもう一方の視点（横から／俯瞰）。小窓をタップで入れ替え |

## 基本仕様（初期値）

| 項目 | 値 | 場所 |
|---|---|---|
| 元手 | 10,000円 | `CONFIG.START_MONEY` |
| 頭数 | 8頭（1枠1頭） | `CONFIG.FIELD` |
| 年間G1 | JRA平地G1 24戦 | `CALENDAR` |
| 出走馬 | 歴代の名馬（約55頭）から8頭 | `LEGENDS` / `makeField()` |
| 控除率（仮） | 単勝 20% / 複勝 20% / 馬連 22.5% / 3連単 27.5% | `CONFIG.TAKEOUT_*`（3連単の見積もりは `SIM_TRI`） |
| レース演出の長さ | 約36秒（スキップ可） | `CONFIG.RACE_SECONDS` |
| セーブ | localStorage `internS_g1predictor_save_v1` | `Save` |

### 予想の要素（どこに「読み」があるか）

| 要素 | 新聞で見える | 効き方 |
|---|---|---|
| スピード・スタミナ・末脚 | 印・前走着順にぼんやり反映 | 基本の速さ / 長距離の失速 / 直線の伸び |
| 脚質（逃げ・先行・差し・追込） | ○ | 序盤は前が有利、ラストは後ろが伸びる |
| 距離適性 | ○（◎○△） | 得意距離から離れるほど遅い |
| 当日の調子 | **×（パドックでだけヒント）** | オッズには反映されない ＝ 穴を見つける手がかり |
| 運 | × | レースごとのブレ |

オッズは「調子を知らない世間」の目線で400回シミュレーションして作っています。
パドックで好調な馬を見抜けると、オッズより勝ちやすい＝儲けのチャンス、という設計です。

調整前の実測（3年分×24戦×20回）: 全頭に単勝を買い続けた回収率 約82〜89%、
1番人気の勝率 約22〜25%。

## レース展開（ドラマ）

勝率のバランスを保ったまま、レースごとに展開が変わるようにしています（`SIM` の設定）。

| 仕組み | 内容 |
|---|---|
| ペース | レースごとにスロー（3割）／平均（4割）／ハイ（3割）。ハイペースほど前の馬が苦しい |
| 大逃げ | 逃げ馬が35%の確率で後続を大きく離す。直線で失速することが多いが、残れば圧勝 |
| まくり | 差し・追込が18%の確率で3〜4コーナーから一気に進出 |
| 直線 | 伸びがゴール前に集中し、追う馬は前との差を詰めやすい（ゴール寸前の逆転・接戦） |
| ハプニング | 出遅れ（0.15〜0.35秒止まる）・暴れる（掛かる）・奮い立つが1頭あたり各3%で起きる（パドックでイレ込んでいた馬は出遅れ・暴れるが2倍） |

実況は、ペース・大逃げ・まくり・ごぼう抜き・決まり手（逃げ切り／差し切り／追い込み／好位抜け出し／まくり）と着差を伝えます。
結果画面にも着差と決まり手が出ます。

## 調整するときに触る場所

`index.html` 内（日本語コメントで区切っています）:

- `CONFIG` — 元手・控除率・演出の長さなど
- `CALENDAR` — G1の名前・月・芝/ダート・距離
- `SIM` — 能力差と運のバランス。`LUCK` を上げると荒れる、`SPEED_W` を上げると堅くなる
- `simulate()` — レースの物理（脚質・スタミナ・適性・調子）
- `computeOdds()` — オッズの作り方
- `paddockComment()` — パドックのコメント
- `commentPhase()` / `commentEvents()` — 実況の文言
- `drawRace()` / `drawOverhead()` — レース画面（序盤＝横から引き、中盤＝俯瞰、ラスト＝寄り）

- Claude が1件ずつ安全かどうかを判定し、安全なものだけをゲームに反映します。
- 判定と理由は次のページに載せます（ログイン不要）。
  https://intern-xi-lilac.vercel.app/intern2026/202610/internS/feedback/
- 判定を追加するときは `feedback/data.js` の配列の先頭に1件足すだけです。
  このページは公開されるので、実名や個人情報は書かないでください。
