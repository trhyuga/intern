# 要望の呼び鈴（internS）

このファイルは、要望フォームの「呼び鈴」用プルリクエストのためだけにあります。
**このプルリクエストはマージしません。**

- Google フォームに要望が送信されると、Google Apps Script がこのプルリクエストに
  「新しい要望あり」とだけコメントします（要望の中身は書きません）。
- Claude はこのプルリクエストを見張っていて、コメントが来たら回答シートを読んで処理します。
- 判定と理由はフィードバックのページに載ります:
  https://intern-xi-lilac.vercel.app/intern2026/202610/internS/feedback/
