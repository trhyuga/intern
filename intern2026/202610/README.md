# intern2026 / 202610

2026年10月から参加するインターン生のフォルダです。
ここに自分の作品フォルダを作って、成果物を置いてください。

## 作品の置き方

1. このフォルダの中に、自分だとわかる名前のフォルダを作る
   （例: `intern2026/202610/neko/`）
2. その中に成果物を置く。Webページやゲームなら、入口を `index.html` にする
3. コミットする

`main` にコミットすると Vercel が自動でデプロイし、次の URL で見られるようになります。

```
https://intern-xi-lilac.vercel.app/intern2026/202610/<フォルダ名>/
```

反映には少し時間がかかります。古い表示のままなら、URL の末尾に `?v=1` のような
クエリを付けてキャッシュを避けてください。

## 守ること

- **実名を書かない**。このリポジトリは公開されています。フォルダ名・コード・
  コメント・README にはニックネームなどを使ってください。
- **自分のフォルダの中だけ**を変更する。ほかの人のフォルダやリポジトリ直下の
  `index.html`（トップページ）は触らない。
- パスワード・APIキーなどの秘密情報をコミットしない。

## 構成

```
intern2026/202610/
├── README.md        ← このファイル
└── <フォルダ名>/     ← 各インターン生の作品
    └── index.html
```
