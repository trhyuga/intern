# 星霜戦記 ―ECLIPSE CHRONICLE― — internU

星の海を舞台にした、ターン制のスペースオペラ戦略ゲームです。
6つの星間国家から1つを選び、内政・外交・艦隊戦で銀河を武力で統一するか、
残るすべての国と同盟を結んで和平を成し遂げます。

- 遊ぶ（main に反映後）: https://intern-xi-lilac.vercel.app/intern2026/202610/internU/
- スマホの縦持ち向け。PC のブラウザでも遊べます。
- HTML + CSS + Vanilla JS。ビルドなし・外部ライブラリなし（文字のフォントだけ Google Fonts）。
- 絵（星雲・惑星・艦・108人の肖像・演出）と音（BGM・効果音）は、すべてプログラムでその場で作っています。画像・音声ファイルはありません。

> 名前・人物・設定・絵はすべてオリジナルです。下の「参考にしたもの」の作品からは、ジャンルと仕組みの考え方だけを借りています。

## ゲームの流れ

```
タップ → オープニング（初回のみ） → タイトル → 国を選ぶ → 第一章の会話
  → 星図で命令 →「月を進める」→ 各国の動き・艦隊の移動・艦隊戦 → 月の報告 → 会話イベント → …
  → 武力統一 / 和平 → エンディング（4部構成）
```

| 画面 | 内容 |
|---|---|
| 星図 | 5つの星系・40の惑星・航路門。つまんで拡大、ドラッグで移動。星や艦隊をタップで選ぶ |
| 惑星 | 開発の向き（産業・研究・防衛衛星・造船所・民生）、総督、投資、造艦、駐留艦、在野の人材 |
| 艦隊 | 司令・副官・陣形、移動の指示、駐留艦の編入、傷ついた艦を下げる |
| 技術と設計 | 兵器・機関・防御・経済の4系統（各8段）と禁忌の技術3つ。船体とモジュールを選んで艦を設計 |
| 人事 | 士官の一覧（能力・性格・忠誠・武功・因縁）、登用、捕虜、褒美 |
| 外交 | 不可侵・通商・同盟・停戦・降伏勧告・宣戦・贈り物・技術供与。使者の交渉力で成功率が変わる。中立の小勢力の依頼 |
| 国政 | 勝利への進み具合、国内の派閥と要求、記録 |
| 参謀 | 参謀・方針・期間を決めて、月を自動で進める（オートモード）。上の「参謀」ボタンから |
| 艦隊戦 | リアルタイム。一時停止して命令できる。陣形・構え・奥の手・地形。「自動で解決」と「観戦する」（司令が指揮し、簡単な指示だけ出す）も選べる |

## 勝利と敗北

- **武力統一**：すべての星を自国か味方（同盟国・盟約を結んだ小勢力）で押さえる
- **和平**：残っているすべての国と同盟を結ぶ（小勢力が残っていれば、それとも盟約が要る）
- ある出来事のあとは、勝利の条件が増える（下の「ネタバレ」を参照）
- **敗北**：自国の星がすべてなくなったとき（首都が落ちても、星が残っていれば遷都して続く）

## 主な仕組み

- **星環協定**：惑星そのものは攻撃できない。軌道の防衛衛星と守りの艦をすべて倒すと制圧できる
- **艦隊戦**：分隊（同じ設計の艦4隻まで）単位で指揮。側面×1.25・背面×1.5 の被害。光線はシールドに弱く、実体弾は装甲に弱く、ミサイルは迎撃される
  - 陣形：紡錘・鶴翼・方円・横列 ／ 構え：突撃・砲撃・防御・後退
  - 地形：星雲（射程が縮む・隠れられる）・小惑星帯（遅い・実弾に強い）・残骸（被害が減る）
  - 司令の奥の手：性格ごとに一度だけ（全艦突撃・鉄壁陣・陽動・応急修理・集中砲火・不退転）
  - **策**：司令官は戦いの中で一度、作戦を仕掛ける。戦術が高いほど策を使い、効きも大きい。どの策を選ぶかは性格と戦況で変わる（策士は伏兵、猛進は突破、奔放は機動、劣勢なら奇策）
    - 挟撃：艦隊を左右に分けて回り込み、両側から挟む
    - 中央突破：紡錘陣で敵の中央を突き抜け、反転して背後を撃つ（押し返されると失敗）
    - 偽装撤退：囮が退いて敵を誘い、隠れていた伏兵が側面から襲う（敵の伏兵は、出てくるまで見えない）
    - 高速機動：足の速い分隊が大きく回り込み、背後を突く
    - 相手の司令官の戦術が上なら、策を **見破られる**（方円陣に組み替える・深追いしない・後ろに備える、など）
  - **戦い方の型**（統率・戦術・性格で決まる。人物の札と会敵の札に出る）：全員が名将ではありません
    - 万能の天才（5人）：好みでなく戦況で策を選び、一戦に二度策を打てる。敵の策もよく見抜く
    - 〇〇の名手（約25人）：得意の一手（挟撃・中央突破・偽装撤退・高速機動のどれか）だけが冴える。他の策は並以下
    - 堅実（約40人）：好みの二つの策を手堅く使う
    - 鉄壁（7人）：攻めの策は使わない。そのかわり被害が少なく（守る時はさらに）、士気が崩れにくく、敵の策を見抜きやすい
    - 凡将（約30人）：策はほとんど使わず、正面から撃ち合う
    - 同じ艦隊で「堅実」の将と戦わせた勝率は、凡将4割・堅実6割台・名手と鉄壁と天才は8〜9割
  - **司令官のいない側**：国の色の一般将兵（艦長・戦隊長など）の顔と台詞が出る
  - **士気**：艦を失う・背後を撃たれる・伏兵に驚く・旗艦を失うと下がり、下がるほど撃つ力が鈍る。落ち込みきると **潰走** する（忠烈の司令官は踏みとどまる）。数で劣っても、名将なら崩して勝てる（大逆転）
  - **援軍・後詰め**：同じ星に来た2つ目以降の艦隊は、遅れて横から現れることがある。統率の高い司令官や沈着・仁徳の司令官は、一隊を後詰めに残し、押されたところで投入する
  - **旗艦**：司令官の乗る分隊（⚑）が沈むと指揮が途絶え、士気が大きく下がる。司令官は戦死・捕縛することもある
  - 山場（策・見破り・伏兵・突破・援軍・潰走・旗艦の喪失）では、司令官の顔と台詞が出る。戦いの流れは結果の画面と作戦室（「戦況」）に残る
  - 自分で指揮するときは「策・〇〇」のボタンで、自分の艦隊に策を指示できる
  - **見た目**（`js/shipart.js`・`js/battle.js`）：
    - 艦は種類ごとに詳しく描きます。駆逐艦・巡洋艦・戦艦・空母・弩級旗艦・防衛衛星に、陰影・装甲板・継ぎ目・砲塔と砲身・艦橋・窓の灯り・国の色帯・機関のノズルがあります。一度描いた絵は覚えておき、回して貼るので、スマホでも軽く動きます。
    - 機関の炎は揺らぎ、前へ出る時は長く伸びます。
    - 蝕は生き物として描きます（胞子・顎・黒冠。脈打つ筋と光る目）。
    - 攻撃：
      - 光線は、外の光・国の色の芯・白い芯の三重です。砲口の光と着弾の光が出ます。大砲は太く長く光り、画面がわずかに揺れます。
      - 電磁投射砲は光る曳光弾、ミサイルは炎と煙の尾を引きます。迎撃されると閃光が出ます。艦載機は光の尾を引きます。
      - シールドに当たると、盾の波紋が出ます。
    - 撃沈：火の玉（白→黄→橙→赤）、衝撃波、燃える破片、回りながら飛ぶ残骸、漂う煙。大きな艦は何度も爆ぜ、画面が揺れます。
    - 傷ついた艦は煙を吐き、深手になると火を噴きます。
    - 背景：深い宇宙のグラデーション・星雲・流れて瞬く星・大気の光る惑星・漂う塵。惑星と塵は戦いごとに一度だけ描いて貼ります。
    - カメラ：生きている艦の広がりに合わせて、戦いの場面へなめらかに寄ります（最大2.2倍）。
  - 艦の傷と練度は次の戦いへ持ち越し。造船所のある星で早く直る
- **国内の派閥**：主戦・通商・技術・融和。戦えば主戦派、条約を結べば通商・融和派、研究すれば技術派が伸びる。毎年1月の評議で主導派閥が決まり、ボーナスが変わる。ときどき要求を出し、応えれば民心が上がる
- **小勢力**：ポルト・リベラ交易港（通商条約2つ）、学術都市アカデメイア（技術合計12）、黒鴉傭兵団（3勝か資金1500）。依頼を果たすと盟約を結べる
- **会話イベント**：各国5章の物語（全30本）と、共通の出来事・絆のある士官の戦死・宿敵が同じ旗の下に入ったときなど、およそ50本
- **エンディング**：①武力統一か和平かの情景 ②国ごとの結末と一枚絵 ③功臣・因縁の二人・戦没者のその後 ④スタッフロールと記録。タイトルの「記録」から見返せる

## 作戦室（オートモードの中心）

このゲームは、参謀に方針を任せて国を動かすのが基本です。新しく始めると、第一章のあとに参謀を選びます（「任せずに、自分で指揮する」も選べます）。

任せている間は、地図の下半分に **作戦室** が開き、毎月の出来事を会話の形で1件ずつ流します。

- 参謀の方針（今月の重点とその理由）
- 命令と、受ける士官の返事（性格ごとの台詞）：艦隊の攻撃・移動・修理、司令や総督の任命、星の重点、造艦の発注、研究、投資、研究費
- 登用：参謀の誘いと、相手の返事（受けた／断った）
- 外交：使者の口上と、相手の君主の返答、成立／不成立。相性の悪い国の反発も出る
- 結果：艦隊戦の勝ち負けと司令の言葉（撃沈・喪失の数）、制圧・失陥、戦死・捕縛、竣工・開発・昇進、小さな出来事、派閥の要求
- 先に出した命令は覚えておき、結果が出た時に「命令『アルテミア攻略』→ 制圧した」のように結びつけて出す
- 銀河の報（ほかの国どうしの戦い・宣戦・同盟）
- 1件ごとに地図がその星へ寄る。速さ（ゆっくり／ふつう／速い）、⏭（その月の報告を一気に出す）、■（止める）。直近12か月分は上へ巻き戻して読み返せる
- 下の「月を進める」は、任せている間は「任せるのを止める」になる

## 人物と関係・物語

士官112名の全員に、経歴・一人称・好むもの、場面ごとの言葉、個人の物語があります。士官どうしの関係は約150組で、国と国の因縁もあります（データは `js/people/`、仕組みは `js/people.js`）。

- **場面ごとの言葉**：攻撃・守り・修理・艦隊司令・総督・重点・使者・研究・登用・参謀・勝利・敗北・開戦・奥の手・昇進・仕官・誘いを断る・捕縛・忠誠が低い時・最期の言葉。作戦室でも、手で命令した時（画面下の吹き出し）でも、その人の言葉で返事をします。
- **個人の物語**：自国に仕えている間、条件がそろうと1人3話ずつ起こります。選択で能力や忠誠が変わります。
- **関係**：絆・想い人・家族・師弟・好敵手・遺恨の6種類。いろいろな場面で話題に出ます。
  - **同じ国にいる時**：時間をおいて3回、二人の関係が進む会話が起こります（人物欄の◆が進み具合）。
  - **敵として現れた時**：作戦室で、敵将と縁のある士官がひと言いいます。
  - **戦場で向き合った時**：「因縁の対決」になります。好敵手と遺恨は火力が上がり、絆のある相手にはためらって火力が下がります。
  - **同じ艦隊の司令と副官の時**：絆が深いほど強くなり、遺恨は和解するまで弱くなります。
  - **参謀として命じる時**：関係を踏まえた言葉をかけます。
  - **相手が捕らわれた時**：身代金で取り戻すか、救出作戦を許すか、待つかを選べます。
  - **相手が死んだ時**：「星になった者」の場面が出ます。絆のある人を失うと戦術が上がり、討った国に3年のあいだ火力が上がります（仇討ち）。その後も時々「追憶」が出ます。
  - **登用する時**：縁のある人が自国にいると誘いが通りやすくなります（遺恨なら通りにくい）。その人が口説きます。
  - **ふだん**：絆は少しずつ忠誠を上げ、遺恨は下げます。
- **メインストーリー**（各国14〜18話＋終幕。`js/people/main0〜5.js`）：序 → 国内の政争 → 予兆 → 蝕 → 退潮と再来 → 根絶 → 終幕、と一本の筋が通ります。
  - 各国に、序で立てた問いがあります（帝国「皇帝とは何か」、共和国「自由を守るために、自由を手放すか」、企業連合「値のつかないものはあるか」、聖教国「何のために光を掲げるのか」、自由同盟「跪かぬ者たちは、どう並んで立つか」、機巧院「継ぐとは何か」）。終幕（勝利の直前、武力統一と和平で別の場面）でその答えが出ます。
  - **派閥で変わる**：主導する派閥（主戦・通商・技術・融和）や派閥の支持の強さで、場面・選択肢・分岐が変わります。
  - **つながる**：選択が flag になり、後の話の分岐や伏線になります。個人の物語の選択がメインの分岐を変え、メインの出来事が個人の物語や幕間のきっかけになります。
  - 政治の画面の「物語の歩み」で、進み具合が見られます。
  - 既存の章を待つ話は、その章が起こらない時（君主がいない等）、8か月たてば先へ進みます。寝返った・捕まった自国の人物の台詞は飛ばします。
- **小勢力の物語**（`js/people/minors.js`）：港湾自由都市・学術都市・黒鴉傭兵団・塔守の民・環の漂泊民の5つに、それぞれ6〜7話の筋があります。盟約を結んだか、他国と結んだか、本拠が落ちたかで分かれ、蝕を経て決着します。
- **国の幕間**：各国11〜15話。メインストーリーの後や flag で起こり、筋とつながっています。
- **国家間の出来事**：15組の国それぞれに、開戦・和平・同盟・通商・星の奪い合い・首都の陥落・時の流れで起こる出来事があります（48話）。自国が当事者なら会話で、そうでなければ作戦室の「銀河の報」で出ます。
- 出来事はひと月に3つまで。優先順は、国の章、死別、国家間の出来事と捕縛、幕間、個人の物語、関係の会話。

## 数値の意味

「兵器3」のような数字だけの表示をやめ、意味が分かる言葉を添えました（`js/gloss.js`）。
- **技術**：段ごとに名前と効果があります（例：兵器 Lv3「高収束光学系」＝艦の火力 +21%）。研究中の画面には「完成すると何が増えるか」と「あと何か月か」が出ます。
- **民心・忠誠・信頼・能力**：数字と一緒に段階の言葉を出します（民心 76〈安定〉、忠誠 88〈心服〉、信頼 −35〈警戒〉、統率 88〈A 優秀〉）。
- **国力比**：「こちらが優勢」「ほぼ互角」などの言葉で表します。
- **戦力**：「小規模」「主力級」などの目安を添えます。
- **開発**：各段の効果を出します（産業は収入の土台 ×1.9、研究は研究の土台 ×2.5、造船所は同時に4隻まで、など）。

## 侵攻の見える化

- 自国が関わる戦いの前には、毎回、画面の上に **会敵の帯** が出ます。例：「⚠ 敵襲：セレス自由共和国のユリウス艦隊（8隻）が ノルトリヒト から グラナート へ侵攻」。双方の戦力も出し、地図は2つの星が見えるように寄ります。帯はタップするか、数秒たつと閉じます。
- 地図には、今月と先月の侵攻を **矢印**（攻めた国の色、出発した星→攻めた星）で描きます。自国が攻められた矢印は赤く点滅します。戦いのあった星には ⚔ と、結果の札（制圧／撃退／無血）がつきます。
- 自国の星の隣に敵の艦隊がいると、その航路が赤い点線になり、星に「！」が出ます。
- 観戦を「なし」にしていても、帯と勝ち負け（撃沈・喪失）は出ます。観戦の結果画面は、タップするまで（最長8秒）残ります。
- 月の報告（手動）の「今月の戦い」と、作戦室の「⚠ 敵襲／⚔ 進攻」の行は、押すとその矢印を地図で見せます。

## 外交の相性と均衡

- 国どうしには相性がある（例：帝国と共和国は独立戦争の因縁で −2、聖教国と機巧院は信仰と機械で −2、共和国と聖教国・自由同盟は +1）
- ある国と条約を結んだり贈り物をしたりすると、その国と相性の悪い国はこちらを疑い（信頼が下がる）、相性の良い国は少し喜ぶ
- 銀河の35%を超える星を持つと、ほかの国から警戒され、信頼が毎月下がる。同盟の申し入れは、すでに結んでいる同盟1つごとに通りにくい
- 同盟は手入れが要る：何もしないと信頼が少しずつ冷め、−10を下回ると同盟を解消されることがある（共通の敵がいる間や蝕の間は保たれる）
- 同盟と通商のしきい値を上げ、参謀の外交の効き目を弱めた

## 戦争と派閥

戦が多く起き、戦うほど得をするように作ってあります。それでいて、国が簡単には滅びないようにしています。

- **派閥の恵み**（主戦派が最も大きく、技術、通商、融和の順）：
  - 主戦派：造艦の費用 −20%・艦の火力 +10%・戦いの武功と戦利品 1.5倍
  - 技術派：研究 +20%
  - 通商派：収入 +12%
  - 融和派：外交が通りやすい +10%・民心 +3
- **戦利品**：星を奪うと、資金と研究が手に入ります。
- **士官の成長**：
  - 戦うと、戦術と統率が伸びます（勝てば大きく、負けても少し）。
  - 総督は政治（研究の星なら技術）が、使者は交渉が、少しずつ伸びます。伸び幅は戦いがいちばん大きくなっています。
- **攻めっ気**：国の攻めっ気は、国の気風に、主戦派の支持・主導・要求を足して決まります。
  - 主戦派の国は宣戦しやすく、艦を多く造り、奪われた星の奪還を最優先にします。
  - 銀河でいちばん大きな国（とくにプレイヤー）には「覇権を阻む」として宣戦します。
- **AI の戦い方**：
  - 戦争中で隣に敵の星がなければ、間の星を取って前へ進みます。
  - 守りが固くても、ときに攻勢をかけます（押し返されることも多い）。
  - 司令官が足りなくても、司令のいない分艦隊（12隻まで）を出し、港に艦を眠らせません。
- **戦の目的**：
  - ひとつの戦で奪う星は2つまで（攻めっ気の強い国は3つまで）です。目的を果たすと、2か月後に停戦します（プレイヤーには停戦の申し入れが来ます）。
  - 停戦から6か月たつと、また宣戦できます。短い戦が繰り返し起こり、戦いは多いのに、国は滅びにくくなっています。
  - 弱った国（星が4つ以下）や、すでに2つの国と戦っている国には、新しく宣戦しません。
  - 負けが込んだ国は、停戦を受け入れやすくなります。
- **滅びにくさ**：
  - 首都は防衛衛星の力が2.2倍、星が3つ以下に追い詰められた国は2倍です。
  - 奪われて間もない、民心の低い星は、もとの国へ寝返ることがあります（艦隊が駐留していれば抑えられます）。
  - 国が広がりすぎる（星12以上）と、民心を保ちにくくなります。
- **蝕との戦い**：各国は自分の方針で蝕に立ち向かいます。
  - 熱意の強い順に、聖教国（預言）、機巧院（記録を継ぐ）、帝国（古の勅書）、共和国、自由同盟、企業連合（損得次第）です。
  - 主導する派閥でも熱意が変わり、主戦派なら強く、通商派なら弱くなります。
  - 熱意が強い国ほど、遠くの裂け目まで艦隊を集めて攻め、封印の理論も急ぎます。

## 階級

士官は武功で **少尉 → 中尉 → 大尉 → 少佐 → 中佐 → 大佐 → 准将 → 少将 → 中将 → 大将 → 元帥** と昇進します。

- 武功は、艦隊戦（勝つと大きい）・総督の務め・外交の使者・参謀の務めで積み上がる。最初の階級は能力と年齢（経験）で決まる
- 階級が上がるほど、艦隊司令として率いられる艦が増える（少尉8隻 … 准将20隻 … 大将・元帥30隻）。艦隊戦の火力もわずかに上がる
- 元帥は、その国でいちばん武功の大きい一人だけ。君主は階級の代わりに称号（皇帝・首相・総裁・聖女・盟主・統括知性）
- 昇進すると記録に残る。肖像の襟章（尉官は線、佐官は銀の星、将官は金の星、元帥は月桂の星）・飾緒・勲章・マントも階級と武功で変わる

## 参謀（オートモード）

参謀にする士官・方針・期間（半年／1年／2年／止めるまで）を選ぶと、その方針を中心に月を自動で進めます。

| 方針 | すること | 得意な能力・性格 |
|---|---|---|
| ⚖ 均衡 | 参謀の得意な分野を軸に、国の様子を見て毎月の重点を選び、万遍なく進める | 得意な上位2分野の平均／沈着・策士 |
| ⚔ 拡張 | 独立惑星や弱った敵を攻める。造艦を増やす | 戦術・統率／猛進・野心 |
| 🛡 専守防衛 | 国境に防衛衛星を築き、攻められたら迎え撃つ | 統率・政治／沈着・忠烈 |
| 💰 富国 | 産業と民生を育て、資金を星に投じる | 政治／仁徳・沈着 |
| 🔬 技術振興 | 研究を伸ばす（禁忌には手を出さない） | 技術／沈着 |
| 🕊 和平外交 | 毎月使者を送り、条約を結んでいく | 交渉／仁徳・策士 |
| （？） | ある出来事のあとに、もう一つ方針が増える | ― |

- 「均衡」は毎月、6つの方針から重点を1つ選ぶ。選び方は「参謀の得意さ」×「国の様子」（敵の艦隊が迫る→専守防衛、資金や民心が乏しい→富国、長い戦で疲れた→和平外交、攻め取れる星がある→拡張、蝕→対蝕作戦）。同じ重点を続けすぎず、しばらく手をつけていない分野にも目を配る。重点と理由は毎月の報告に出る
- 参謀（7割）と君主（3割）の能力と性格から、方針ごとの向き不向きが **S〜D** で出る。奔放な者は方針によって当たり外れがある
- 向いているほど方針の効き目（収入・研究・外交の通りやすさ・戦いの火力や守り）が強く、しくじり（月の仕事の抜け）が少ない
- 艦隊戦の扱いを選べる：「見る」（参謀・司令が指揮する戦いを観戦し、簡単な指示を出せる）／「大きな戦いは指揮」（20隻以上は自分で指揮、ほかは見る）／「見ない」（結果だけ）。会話の出来事は途中で見られる
- 観戦中の簡単な指示：⚔全軍突撃・🎯砲撃戦・🛡守りを固める・↩参謀に任せる、敵をタップして集中攻撃、奥の手、撤退、結果へ（一気に終わらせる）。結果はタップで閉じる（最長8秒で自動的に閉じ、次の月へ進む）
- 任せている間は、毎月の報告を上の帯に出す：参謀がしたこと（重点の切り替え・投資・発注・登用・艦隊の移動・申し入れ）、月の要約（資金の増減・研究の進み・次に上がる開発とあと何か月か）、小さな出来事、ほかの国どうしの出来事（銀河の報）。帯をタップすると、その月の報告をすべて読める
- 富国の参謀は毎月、余った資金を人口の多い星の開発に投じる。技術振興の参謀は研究の星に投資し、残りを研究費（資金→研究）に回す。どちらも得意なほど多く・効率よく
- **国内の派閥への配慮**：
  - 「均衡」の重点選びに派閥の声が入ります。主戦派が強いほど拡張が、技術派なら研究が、通商派なら富国が、融和派なら和平外交が選ばれやすくなります。主導する派閥の方針はさらに選ばれやすく、主戦派が戦果を求めていれば拡張を優先します。
  - 拡張以外の方針でも、戦争中の敵国の星は攻めます。主戦派が強いほど、攻めっ気が上がります。
  - 和平外交の方針では、主戦派が弱い時だけ、大国を攻めません。
- **参謀の宣戦**：拡張の月や、主戦派の声が大きい時は、隣の大国に宣戦を進言します（作戦室に、参謀の進言と君主の裁可が出ます）。
  - 相手は、国境を接し、こちらより弱く、同盟していない国です。
  - 不可侵や通商の約束を破るのは、主戦派がとても強い時だけです。
  - 蝕が攻めてきている間は、宣戦しません。
- 期間が終わる・首都が落ちる・星を3つ失う・大きな異変が起きる、のどれかで止まり、参謀が成果を報告する。帯の「■ 止める」でいつでも自分の指揮に戻れる
