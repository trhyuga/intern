# 星霜戦記 ―ECLIPSE CHRONICLE― — internU

星の海を舞台にした、ターン制のスペースオペラ戦略ゲームです。
6つの星間国家から1つを選び、内政・外交・艦隊戦で銀河を武力で統一するか、
残るすべての国と同盟を結んで和平を成し遂げます。

- 遊ぶ（main に反映後）: https://intern-xi-lilac.vercel.app/intern2026/202610/internU/
- スマホの縦持ち向け。PC のブラウザでも遊べます。
- HTML + CSS + Vanilla JS。ビルドなし・外部ライブラリなし（文字のフォントだけ Google Fonts）。
- 絵（星雲・惑星・艦・108人の肖像・演出）と音（BGM・効果音）は、すべてプログラムでその場で作っています。画像・音声ファイルはありません。

> 名前・人物・設定・絵はすべてオリジナルです。下の「参考にしたもの」の作品からは、ジャンルと仕組みの考え方だけを借りています。

## ゲームの流れ

```
タップ → オープニング（初回のみ） → タイトル → 国を選ぶ → 第一章の会話
  → 星図で命令 →「月を進める」→ 各国の動き・艦隊の移動・艦隊戦 → 月の報告 → 会話イベント → …
  → 武力統一 / 和平 → エンディング（4部構成）
```

| 画面 | 内容 |
|---|---|
| 星図 | 5つの星系・40の惑星・航路門。つまんで拡大、ドラッグで移動。星や艦隊をタップで選ぶ |
| 惑星 | 開発の向き（産業・研究・防衛衛星・造船所・民生）、総督、投資、造艦、駐留艦、在野の人材 |
| 艦隊 | 司令・副官・陣形、移動の指示、駐留艦の編入、傷ついた艦を下げる |
| 技術と設計 | 兵器・機関・防御・経済の4系統（各8段）と禁忌の技術3つ。船体とモジュールを選んで艦を設計 |
| 人事 | 士官の一覧（能力・性格・忠誠・武功・因縁）、登用、捕虜、褒美 |
| 外交 | 不可侵・通商・同盟・停戦・降伏勧告・宣戦・贈り物・技術供与。使者の交渉力で成功率が変わる。中立の小勢力の依頼 |
| 国政 | 勝利への進み具合、国内の派閥と要求、記録 |
| 参謀 | 参謀・方針・期間を決めて、月を自動で進める（オートモード）。上の「参謀」ボタンから |
| 艦隊戦 | リアルタイム。一時停止して命令できる。陣形・構え・奥の手・地形。「自動で解決」も選べる |

## 勝利と敗北

- **武力統一**：すべての星を自国か味方（同盟国・盟約を結んだ小勢力）で押さえる
- **和平**：残っているすべての国と同盟を結ぶ（小勢力が残っていれば、それとも盟約が要る）
- 「蝕」が来たあとは、どちらの勝利にも、蝕の裂け目の核を砕くことが要る
- **敗北**：自国の星がすべてなくなったとき（首都が落ちても、星が残っていれば遷都して続く）

## 主な仕組み

- **星環協定**：惑星そのものは攻撃できない。軌道の防衛衛星と守りの艦をすべて倒すと制圧できる
- **艦隊戦**：分隊（同じ設計の艦6隻まで）単位で指揮。側面×1.25・背面×1.5 の被害。光線はシールドに弱く、実体弾は装甲に弱く、ミサイルは迎撃される
  - 陣形：紡錘・鶴翼・方円・横列 ／ 構え：突撃・砲撃・防御・後退
  - 地形：星雲（射程が縮む・隠れられる）・小惑星帯（遅い・実弾に強い）・残骸（被害が減る）
  - 司令の奥の手：性格ごとに一度だけ（全艦突撃・鉄壁陣・陽動・応急修理・集中砲火・不退転）
  - 艦の傷と練度は次の戦いへ持ち越し。造船所のある星で早く直る
- **国内の派閥**：主戦・通商・技術・融和。戦えば主戦派、条約を結べば通商・融和派、研究すれば技術派が伸びる。毎年1月の評議で主導派閥が決まり、ボーナスが変わる。ときどき要求を出し、応えれば民心が上がる
- **小勢力**：ポルト・リベラ交易港（通商条約2つ）、学術都市アカデメイア（技術合計12）、黒鴉傭兵団（3勝か資金1500）。依頼を果たすと盟約を結べる
- **蝕（エクリプス）**：84か月前後に、銀河の外から星を喰う群れが来る（予兆が2回ある）。禁忌の技術をどこかの国が修めるたびに早まる。裂け目の核を砕けば退く
- **会話イベント**：各国5章の物語（全30本）と、共通の出来事・絆のある士官の戦死・宿敵が同じ旗の下に入ったときなど、およそ50本
- **エンディング**：①武力統一か和平かの情景 ②国ごとの結末と一枚絵 ③功臣・因縁の二人・戦没者のその後 ④スタッフロールと記録。タイトルの「記録」から見返せる

## 階級

士官は武功で **少尉 → 中尉 → 大尉 → 少佐 → 中佐 → 大佐 → 准将 → 少将 → 中将 → 大将 → 元帥** と昇進します。

- 武功は、艦隊戦（勝つと大きい）・総督の務め・外交の使者・参謀の務めで積み上がる。最初の階級は能力と年齢（経験）で決まる
- 階級が上がるほど、艦隊司令として率いられる艦が増える（少尉8隻 … 准将20隻 … 大将・元帥30隻）。艦隊戦の火力もわずかに上がる
- 元帥は、その国でいちばん武功の大きい一人だけ。君主は階級の代わりに称号（皇帝・首相・総裁・聖女・盟主・統括知性）
- 昇進すると記録に残る。肖像の襟章（尉官は線、佐官は銀の星、将官は金の星、元帥は月桂の星）・飾緒・勲章・マントも階級と武功で変わる

## 参謀（オートモード）

参謀にする士官・方針・期間（半年／1年／2年／止めるまで）を選ぶと、その方針を中心に月を自動で進めます。

| 方針 | すること | 得意な能力・性格 |
|---|---|---|
| ⚔ 拡張 | 独立惑星や弱った敵を攻める。造艦を増やす | 戦術・統率／猛進・野心 |
| 🛡 専守防衛 | 国境に防衛衛星を築き、攻められたら迎え撃つ | 統率・政治／沈着・忠烈 |
| 💰 富国 | 産業と民生を育て、資金を星に投じる | 政治／仁徳・沈着 |
| 🔬 技術振興 | 研究を伸ばす（禁忌には手を出さない） | 技術／沈着 |
| 🕊 和平外交 | 毎月使者を送り、条約を結んでいく | 交渉／仁徳・策士 |
| ☄ 対蝕作戦 | 蝕の星と裂け目の核を全力で攻める（蝕が来てから） | 統率・戦術・技術／忠烈 |

- 参謀（7割）と君主（3割）の能力と性格から、方針ごとの向き不向きが **S〜D** で出る。奔放な者は方針によって当たり外れがある
- 向いているほど方針の効き目（収入・研究・外交の通りやすさ・戦いの火力や守り）が強く、しくじり（月の仕事の抜け）が少ない
- 「艦が20隻以上の大きな戦いは自分で指揮する」を選べる。会話の出来事は途中で見られる
- 期間が終わる・蝕が現れる・首都が落ちる・星を3つ失う、のどれかで止まり、参謀が成果を報告する。帯の「■ 止める」でいつでも自分の指揮に戻れる

## 国（6つ）

| 国 | 特徴 | ボーナス |
|---|---|---|
| ヴァルディス帝国 | 若き皇帝と摂政の宮廷劇。主戦派が強い | 艦の火力 +6% |
| セレス自由共和国 | 議会と英雄提督の綱引き。融和派が強い | 外交 +12% |
| メルカトル企業連合 | 取締役会の権力争い。通商派が強い | 収入 +18% |
| ルミナ聖教国 | 蝕を預言する聖女。民心が安定 | 民心 +10 |
| ノヴァ自由同盟 | 辺境の氏族の寄り合い。艦が速い（上級者向け） | 艦の速さ +15% |
| ゼノア機巧院 | 古代の記録を継ぐ人と機械。技術が高い | 研究 +20% |

## ファイル構成

```
internU/
├── index.html          画面の骨組み
├── style.css           見た目
├── README.md           このファイル
└── js/
    ├── config.js         題名など（題名を変えるときはここだけ）
    ├── data_world.js     星系・惑星・航路・小勢力
    ├── data_factions.js  6つの国・始まりの関係・派閥
    ├── data_ships.js     船体・モジュール・技術・禁忌・蝕の艦
    ├── data_officers.js  士官108名・因縁・奥の手
    ├── data_events.js    会話イベント
    ├── art.js            艦・紋章・星雲・惑星の絵
    ├── portrait.js       士官の肖像（名前から顔立ちが決まる。表情5種）
    ├── audio.js          BGM と効果音（Web Audio で合成）
    ├── game.js           状態・内政・研究・造艦・派閥・勝敗・セーブ
    ├── designer.js       艦の設計（AI の自動設計）
    ├── diplomacy.js      外交
    ├── eclipse.js        蝕
    ├── ai.js             AI の国
    ├── battle.js         艦隊戦（表示つき・自動解決の両方）
    ├── starmap.js        星図
    ├── story.js          会話イベントの進行
    ├── staff.js          参謀（オートモード）
    ├── turn.js           月の進行
    ├── cinema.js         タイトル背景・オープニング・エンディング・スタッフロール
    └── ui.js             画面と操作
```

セーブはブラウザの localStorage に、ひと月ごとに自動で保存されます。

## 確かめたこと

- Playwright で縦持ちスマホ（390×844）を表示し、オープニング・タイトル・国選び・会話・各一覧・艦隊戦・エンディング（統一／和平）をスクリーンショットで確認。コンソールのエラーなし、横はみ出しなし
- 全勢力を AI にして150〜200か月を高速で回し、例外が出ないこと・蝕が来て退けられること・国の興亡が起きることを確認
- 画面の操作（月を進める・艦隊戦の自動解決・会話の選択・申し入れ）を3つの国で自動で回し（合わせて約180か月）、エラーが出ないことを確認

- 『銀河英雄伝説』のゲーム作品：陣形と提督の能力、会戦の結果で物語が分かれる
- 『Homeworld』：艦隊と傷の持ち越し、陣形、戦場の地形
- 『Master of Orion』：艦の設計、戦闘の自動解決
