# 群雄天下 ― 三国英傑伝 ― （internT）

後漢末の中国を舞台にした、**オリジナルの三国志戦略シミュレーション**です。
iPhone での縦画面プレイを想定しています。ビルドは不要で、外部ライブラリも使っていません。HTML・CSS・Vanilla JS・Canvas 2D・Web Audio だけで動きます。

- プレイ（main に反映後）: https://intern-xi-lilac.vercel.app/intern2026/202610/internT/

> 特定の市販ゲームの再現ではありません。ルール・画面・名前・音楽はすべて独自です。
> 三国志の史実・演義に登場する人物と地名を題材にしています。
> 武将の能力値・性格はこのゲーム独自の目安です。登場年・没年は**おおよそ**で、生没年がはっきりしない人物には仮の年を入れています。
> 地図は実際の地理を大まかに崩したもので、正確な位置ではありません。
> 肖像・背景・音楽・効果音は、すべてプログラムでその場で描画・合成しています。画像や音のファイルは使っていません。

### 即位（公→王→皇帝）

都市が増えると、家臣（軍師か知力・魅力の高い者）の勧めで君主が位に就く。位は勢力に残り、跡継ぎも引き継ぐ。

| 位 | 条件 | 表示の例 |
|---|---|---|
| 公 | 都市10以上 | 魏公 曹操軍 |
| 王 | 都市16以上 | 魏王 曹操軍 |
| 皇帝 | 都市24以上 | 皇帝 曹操軍 |

- 位が上がるのはゲーム開始から1年後以降、しかも1年に1段まで（208年の曹操なら209年に魏公、210年に魏王）
- 国号は君主ごと（曹操＝魏、劉備＝漢、孫権＝呉、袁術＝仲 など）。それ以外は本拠の都市名の1字
- 即位のとき：家臣の忠誠＋、全都市の民忠＋、君主の魅力＋。合戦では位1段ごとに将兵の士気＋4
- 曹操・劉備・孫権などは専用の即位の言葉がある。他勢力が王・皇帝を称すると「天下の動き」として知らせる
- 画面上部の勢力名の前に金色の位の札が出る

### 音楽と効果音

- **楽器**：筝・二胡（しゃくり上げとビブラート）・笛（息の音つき）・琵琶（長い音はトレモロ）・笙の和音・大太鼓／小太鼓／縁打ち／シンバル・鈴・銅鑼・角笛を合成
- **曲（11曲）**：タイトル／地図（春・夏・秋・冬で曲が変わる）／合戦（攻め）／籠城（守り）／劣勢（自軍の見通しが悪くなると切り替わる）／一騎討ち／エンディング／悲しみ。各曲はA・B（・C）の節があり、2周目からは筝の装飾音や重ねが入って単調にならない
- **効果音（約40種）**：開墾（鍬と小鳥）・商業（銭の音）・修築（槌）・訓練（太鼓と掛け声）・徴兵・施し・大成功のきらめき・登用・季節の変わり目・同盟・出来事の鈴・訃報／合戦の鬨の声と角笛・斬撃・弓（大部隊は一斉射撃）・火計・混乱・城門破壊・馬の蹄・援軍の角笛・背水の陣・勝利のファンファーレと歓声・敗北／一騎討ちの風切り・打ち合い・受け止め・会心の一撃・必殺技・とどめの一撃（ふつう／会心・必殺技で討ち取った時はさらに大きく）
- **環境音**：合戦が雨の日は雨音が流れ、時々雷が鳴る

## ゲームの流れ

```
タップ → オープニング → タイトル → シナリオ選択 → 君主選択 → 全国地図（季節ごとに命令）
                                                     ├ 出陣 → 戦場（マス目の戦術マップ／委任も可） → 捕虜の処遇
                                                     └ 季節を進める → 他勢力の行動・敵襲 → 収穫・災害・寿命・謀反
        全勢力を滅ぼす → 統一エンディング（功臣のエンドロール）
        自勢力が滅ぶ  → 敗北エンディング
```

## 遊びの柱

| 柱 | 内容 |
|---|---|
| 武将が主役 | 命令はすべて武将が1人1回ずつ行う。誰に任せるかで成果が変わる（政治→内政、魅力→徴兵・登用、知力→計略、統率→訓練・修築） |
| 性格で動く | 13種の性格（忠義・野心・剛勇・猪突・智謀・神算・仁徳・慎重・臆病・水軍・騎馬・弓術・治世） |
| 表情 | 肖像は名前から顔立ちが決まり、通常・喜・怒・哀・驚の5表情に変わる。主要武将には専用の顔立ち（赤ら顔、長いひげ、片目など） |
| 戦場 | 9×11マス。城門を壊し、本丸を占領するか、敵の総大将★を倒す。火計・混乱・一騎討ち・弓の射撃・川と浅瀬・天候・兵糧・包囲・夜戦 |
| 一騎討ち | 「攻める／渾身／守る／退く」を選ぶ演出つきの決闘。負けた側は討死・捕縛・逃走。武力が高いほど**会心の一撃**（約2倍、剛勇・豪傑は出やすい・最大20%）が出る。必殺技を持つ武将の「渾身」は35%で**必殺技**に変わる（必ず当たり約2.6倍、画面が暗転して技名が出る）。闘技場では武将ごとの武器（関羽の青龍刀、張飛の蛇矛、呂布の方天画戟など）と馬の色で駆け寄って打ち合う。**とどめの一撃**は特別な演出：暗転して寄り（溜め）→画面を斜めに走る一閃・集中線・白い閃光・衝撃の輪・飛び散る火花→討たれた側は馬ごと宙に舞って倒れ、金の火の粉が舞い上がる。「討ち取ったり！」の大きな文字と専用の効果音（大太鼓・金属音・銅鑼・歓声）。会心の一撃・必殺技で討ち取った時は、溜めの音が上がりきってから斬り、閃光・揺れ・火花・輪がさらに大きく、鈴の音のきらめきが加わる |
| 軍師オート | 下の「軍師」から開始。任命した軍師が内政・人事・計略・外交・出陣をすべて決め、都市画面を開いてボタンを押す様子や戦場の采配をそのまま見せる。知力で判断の正確さが、性格で采配の癖が変わる（下表）。「止める」でいつでも自分の操作に戻れる |
| 観戦と委任 | 戦い方は「自ら指揮」「軍師に任せて観戦」「委任（結果だけ）」の3つ。観戦中も「ここから自分で指揮する」で切り替えられる |
| 魅力の高い将の施し | 魅力70以上の将は、自分が納得する民忠（30＋魅力×0.6：魅力80で78、魅力100で90）に届くまで、内政で施しを選びやすい。コンピュータの勢力は、民忠40未満の施しや敵が迫った時の徴兵など急ぎの用の次に施しを選ぶ。軍師オートでは施しを重く見るが、最優先の項目には譲る。民忠が上がると、戦で守る時に市民兵が立ち上がりやすくなる（総大将の魅力78以上・民忠75以上が条件）。試算（194年の劉備で8季節回した時の敵の都市）：魅力70以上の将がいる都市の民忠の平均 51→66、市民兵の条件を満たす都市 0→25（182都市中） |
| 負け戦での将の損失 | プレイヤーの武将が少ないうちは、負けても将を失いにくい。戦で討死・捕縛となった将は、倍率の残り（1−倍率）の確率で「深手を負いながらも逃げ延びた」になり、近くの自分の都市へ戻る。捕らえられても、敵に降る・処断される確率に同じ倍率が掛かる。倍率：武将3人まで0.25・6人まで0.4・10人まで0.65・14人まで0.85・15人以上1（今まで通り）。敵の勢力には掛からない。試算（2人が討死・捕縛になる負け戦）：将を失う割合は 3人のとき12%・6人16%・10人42%・20人74% |
| 台詞 | 内政・出陣・敵襲・勝敗・一騎討ち・捕虜・処断・病死・寝返り・謀反・雑談など36場面。性格と人物ごとに口調が変わる（関羽は「某」、張飛は「俺」で劉備を「兄者」と呼ぶ、など）。戦場では頭上に掛け声が出る。列伝の「話を聞く」で、忠誠に応じた本音が聞ける |
| 絆 | 劉備・関羽・張飛など、決まった組み合わせが同じ戦場にそろうと強くなる |

### 性格が効く場面（例）

- **猪突**（張飛・甘寧など）は、戦場で命令を無視して突撃することがある
- **野心**（呂布・司馬懿など）は離間が2倍効き、忠誠が下がると**謀反を起こして独立**する
- **忠義**（関羽・趙雲など）には離間・引き抜きが効かず、専用の台詞で突っぱねる
- **臆病**な武将は、兵が3割を切ると勝手に退却する
- 諸葛亮は、君主自らが3度訪ねないと仕官しない（三顧の礼）

## 修行（人事）

お気に入りの武将を鍛える命令。その武将の1回の行動を使い、能力（統率・武力・知力・政治・魅力）を1つ選んで伸ばす。費用はかからない。

| 今の値 | 伸び |
|---|---|
| 〜49 | +3〜5 |
| 50〜69 | +2〜3 |
| 70〜79 | +1〜2 |
| 80〜89 | +1 |
| 90〜94 | 50%で+1 |
| 95〜98 | 10%で+1 |
| 99 | 上がらない（選べない） |

選ぶ画面に、それぞれの見込みを表示する。軍師オートは修行を使わない。

修行の台詞は、能力ごと×性格（約80種）に、苦手な能力（60未満）を鍛えたとき・大きく伸びたとき（+3以上）・伸びなかったときの台詞がある。関羽・張飛・呂布・許褚・諸葛亮・劉禅・曹操・呂蒙・黄忠・趙雲には専用の台詞もある（専用と性格の台詞が半々で出る）。

## 命令の当たり・はずれ

開墾・商業・修築・施し・徴兵・訓練は、毎回「当たり【大成功】」「普通」「はずれ」のどれかになる（`Game.roll()`）。

| 結果 | 起きやすさ | 効果 |
|---|---|---|
| 大成功 | 15%＋（能力−60）÷200。称号の上位者は+12%（5〜50%） | 1.6〜1.9倍 |
| 普通 | 残り | 0.9〜1.1倍 |
| いまひとつ（表示なし。台詞と表情で伝わる） | 20%−（能力−60）÷200（3〜35%） | 0.35〜0.6倍 |

例：政治98の荀彧は大成功44%・いまひとつ3%、政治22の許褚は大成功4%・いまひとつ35%。
台詞も結果ごとに変わる（`farm_great` `farm_poor` など）。普通の台詞はコマンドごとに6〜10種、当たり・はずれは4〜5種＋性格別。共通の台詞が多い場面では、性格の台詞ばかりにならないよう混ぜて出す。

## イベント

`js/events.js`。季節の終わりに判定する。プレイヤーの勢力に起きたものは会話で知らせ、他勢力のものは静かに反映（大きな史実は「天下の動き」として知らせる）。

**不定期イベント**（都市は各5%／季節、武将は各2.5%／季節。1季節に表示するのは最大5件）

**大きな敵勢力ほど悪い出来事が増える（大勢力の驕り）**：敵の勢力は、都市5つまでは今まで通り。それを超えると1都市ごとに「災いの強さ」k が +0.15（最大3倍＝都市18以上）。プレイヤーの勢力はいくら大きくなっても1倍のまま
- 都市の悪い出来事（大地震・大火・盗賊・干ばつ・凶兆・異民族・兵の脱走・蝗・疫病・大雪・偽商人）が、各都市に 8%×(k−1) の確率で余分に起き、被害（下がる数値）は k 倍
- 武将の悪い出来事（酒の失敗・不満・病・寝坊・馬が逃げた）も 2.5%×(k−1) の確率で余分に起き、忠誠の下がり方は k 倍（忠誠が下がると謀反も起きやすくなる）
- 大勢力だけの災い（季節ごとに 25%×(k−1)、最大60%）：宮廷の内紛（何人もの忠誠 −8×k）・役人の腐敗（全都市の金 −12%×k）・重税への不満（全都市の民忠 −5×k）・辺境の兵の疲れ（前線の兵 −6%×k・訓練 −6×k）・逃亡兵の続出（全都市の兵 −4%×k）・兵糧の目減り（全都市の兵糧 −10%×k）。起きたら「天下の動き」として1季節に1件まで知らせる
- 大軍を養いきれず、毎季節、全都市の兵が (k−1)% ずつ散っていく（都市18以上で −2%）
- 目安（1季節あたり）：都市18の敵勢力は 兵 −約3.4%・金 −約5%・民忠 −約2（各都市）・武将の忠誠 合計 −約15。都市12は 兵 −約1.7%、都市8は 兵 −約0.8%

- 季節：名産・故郷の台詞がないとき、25%で季節ならではの一言（春の種まき・秋の取り入れ・冬の炭売りなど）
- 地勢：名産の台詞がないとき、ときどき大河沿い・山地・平野ならではの一言になる
- 流言：成功すると70%で土地柄に応じた追加の効果が出る。漢中は五斗米道の信者が騒ぐ（民忠）、都（洛陽・長安・許昌）は「天子をないがしろにしている」（君主の魅力）、辺境は異民族をけしかける（兵）、大河沿いは「船底が腐っている」（訓練）、山地は「宝が埋まっている」（金）、商業の盛んな町は「銭の値打ちが下がる」（商業）、兵糧の多い町は「米に毒」（兵糧）。失敗したときも、ときどきとぼけた知らせになる

**台詞**：内政・雑談・成功／失敗の台詞を性格ごとに追加。馬良・太史慈・徐晃・張郃・夏侯淵・曹仁・貂蝉・孟獲・馬岱・関平・周倉・程昱・荀攸・于禁・楽進・李典・顔良・文醜・張角・劉表・劉璋・公孫瓚・曹丕・曹植・鄧艾・王平・厳顔にも、逸話にちなむ雑談の台詞を足した。張飛・許褚・曹操・劉禅・呂布・諸葛亮・黄忠など19人に、思わずにやりとする台詞を足した

## 軍師オートの采配

- ゲーム開始時の操作説明のあと、軍師（知力がいちばん高い家臣）が軍師オートの使い方（下の「軍師」から任せる・3つの任せ方・「止める」・見る速さ・タップで先へ）を説明する
- 合戦の観戦中に「止める」を押すと、決着を待たずにその場で指揮が戻る（次の自軍の手番から自分で動かせる。任せたいときは「委任」）。止める指示のあとの会話や結果表示は、自動では流れず手動で進む。合戦が終わるとオートが止まる
- 軍師オート中は画面が自動で消えないようにする（Screen Wake Lock。iPhoneのSafariはiOS 16.4以降、ホーム画面に追加した場合はiOS 18.4以降。対応していない端末では何もしない）。他のアプリに切り替えると解除され、戻るとかけ直す。オートを止めると解除
- 見る速さは「普通→速い→超速」の3段階（軍師のバーのボタンか、軍師メニューで切り替え）。超速は会話を一瞬（0.28秒）だけ見せて流し、他の待ち時間も4分の1にする（1季節がおよそ5分の1の時間で進む）
- 会話の折り返しで最後の行に2文字以下だけ残るときは、字間を少し詰めて前の行に収める。詰めても収まらなければ、最後の5文字を折り返さないようにして、前の行から何文字か連れてくる
- 会話の表示時間は文字数に応じて長くなる（約0.9秒＋1文字50ms、最大7秒）。「速い」でも長い文が読めるよう、速さの効きを弱めている（約1.5倍速）。会話欄（画面のどこでも）をタップすると、すぐ次へ送れる。会話の表示中も、上の「止める」「速さ」ボタンは押せる

**内政の基本（性格や知力に関係なく守る）**
- 上限に達した値（農業・商業・城壁・訓練・民忠）は上げようとしない。同じ都市で何人かに割り振るときも、前の人の成果を見込んで上限を超えて重ねない
- 民忠40未満なら施しが最優先。徴兵は民忠を下げるので、民忠50未満ではしない
- 前線で兵が敵の脅威に足りないときは徴兵を優先
- 性格の癖と知力のぶれは、この基本の範囲内で優先度を上下させる「掛け算」として効く（0 を 0 以外にはしない）
- 知力の低い軍師は、命令の選び方は基本どおりだが、誰に任せるかが大ざっぱ

**兵が揃ったら攻める（最優先）**
- 前線の都市に兵が2万以上（野心・猪突の軍師なら1.5万以上）いれば、毎季節、隣で一番落としやすい敵都市へ攻め込む。内政・計略より先に決め、1季節の出陣数の上限にも数えない
- 見送るのは、攻め先の守りの強さがこちらの1.5倍以上あるときだけ
- 守備兵は「今の兵の25%か5,000の多い方」だけ残す。武将が足りなければ周りの都市から呼ぶ
- 兵糧は10日分あれば出陣（残す兵の1季節分だけ残す）。出陣の直前の見積もり直しはしない

**出陣の基本（城を空にしない・勝てそうな兵で戦う）**
- 守備兵を必ず残す：前線4000・後方2000、今の兵の2.5割、隣の敵の最大兵力×性格の係数（慎重0.6／普通0.45／野心・猪突0.35。城の守りは兵1人あたり約1.4倍強いので、この程度で持ちこたえられる。知力が低いと甘く見る）のうち一番多い数
- 敵の強さ（兵・訓練・武将・城壁（1.1＋城壁÷1000×序盤の効き目 倍。実際の合戦の守りの強さに合わせた）・隣の都市や同盟国から来そうな援軍の4割）を見積もり、勝つのに必要な兵を計算。余裕（知力が高いほど多い、慎重なら更に多め）を足した分だけ連れていく。出す兵は最低3000
- 求める力の比（見積もり。1.0で互角）は軍師の優秀さで決まる：知力の高い軍師 1.2倍、ふつう 1.08倍、知力の低い軍師 0.95倍（見積もりのぶれも大きい。出せる兵をすべて連れていくようにしたので、以前の1.3倍・1.15倍から下げた）。慎重なら高く、野心・猪突・剛勇なら低くなる。兵が揃った攻め（2万以上）もこの基準で判断し、5万以上の大軍は基準を下げる（知力の高い軍師 1.0倍、ふつう 0.85倍、低い軍師は構わず攻める）。消耗戦は兵8000以上で、知力の高い軍師 0.9倍・ふつう 0.75倍の見込みがあるときだけ
- 君主が軍師を兼ねるときは、君主らしい言い切りの口調で采配する（「許昌を攻める。夏侯淵、兵3,000を率いて行け」など）。節目の言葉では、知力の一番高い家臣が軍師の役で話す
- 1つの都市で足りないときは、周りの自都市から兵と待機中の武将を合流させてから攻める（武将1人が率いられる兵には上限があるため）
- それでも届かないときは、一番取りやすい攻め先を決めて、手前の拠点に季節をまたいで兵を集める（後方からの輸送と、拠点での徴兵）
- **消耗戦**：一度で落とせる見込みがなくても、守りの兵を残したうえで（周りの自都市からの合流も含めて）敵の兵の数倍を出せるなら攻め込む。目安は普通2.5倍、慎重3倍、野心・猪突2倍。30日で落としきれなくても敵兵を削り、次の攻めで落とす。通常の攻めを優先し、その次に検討する
- 総大将は統率が高く猪突でない武将（知力の高い軍師ほど、この選び方をする）。戦場では総大将は前に出すぎず、同格以上からの一騎討ちは軍師が止める
- 出陣の直前にもう一度見積もり直し、兵糧が20日分持てなければ見送る
- 前線の都市では、統率の高い武将を1人は城に残す。君主は他に武将がいれば出陣させない
- コンピュータ勢力の出陣と、手動出陣の兵数の初期値も、守備兵を残した数にしている
- コンピュータ勢力の見積もり：その勢力でいちばん知力の高い武将が見立て役。実際に出せる兵（守備兵を残し、将の率いる上限まで）と、相手の兵・訓練・将・城壁・隣の都市から来そうな援軍を比べる。見立て役が賢いほど見積もりのぶれが小さく、求める勝ち目が高い（最大1.2倍）。試算（コンピュータどうし、12季節×6回）：攻めの回数は約3分の2になり、成功率は約63%→約80%
- コンピュータ勢力の守り：後方の兵を前線へ送るほか、前線どうしでも、脅威に対して余裕のある都市（脅威の1.5倍と5000の多い方を超える分）から、兵の足りない隣の都市へ回す。総大将には、見立て役が賢い勢力なら統率が高く猪突でない将を選ぶ
- コンピュータ勢力の攻め気：見積もった力の比が1.0以上（野心0.9、猛将がいれば0.8）で攻める。プレイヤーへの攻め気は序盤は控えめで、ゲームが進むほど強まる（攻め気＝「(プレイヤーの都市数−3)÷7」と「経過した季節÷16」の大きい方、0〜1）。プレイヤーの都市の評価は0.8倍（序盤）〜1.25倍（終盤）、手薄な都市（兵が自分の都市の平均の6割未満）・武将のいない都市はさらに最大1.2倍・1.15倍。プレイヤーの都市を狙うのを見送る確率は序盤35%→終盤0%（他の相手は15%）。出陣の条件は兵5000・兵糧4000以上、守備兵は前線3000・兵の25%・隣の敵の40%のうち多い数
- 城門を破ったとき、崩れるのは「門だけ」「門と片側の城壁」「門と両脇の城壁（突入口3マス）」のどれか。城壁の値が高いほど門だけで済みやすい（城壁800なら門だけ65%・両脇15%、城壁300なら門だけ37%・両脇34%）

**計略と一騎討ち（オートでも行う）**

- 一騎討ちは、武力の高い武将（78以上）ほど挑めそうな敵将の隣へ進んで名乗りを上げる。剛勇・猪突は格上にも挑み、豪傑同士は特に引き合う
- 城の兵糧：守り手も城の兵糧を食べる（1日に兵の3%）。尽きると毎日士気が20下がり、守り手が皆、士気30未満になると「城の兵糧が尽き、城門が開かれた」で攻め手の勝ち。守り切った城の兵糧は、籠城で食べた分だけ減る。画面上の兵糧は「攻◯日 守◯日」（あと何日もつか）で表示する
- 一旦退いた部隊のその後：兵が減って後ろへ下がった部隊は、敵から離れて2日たつと、どちらの兵糧が先に尽きるかを比べる（攻め手は30日の期限も兵糧と同じに数える）
  - 敵の兵糧が先に尽きるなら、離れたまま逃げ続ける（とどめを刺せる敵が隣にいる時だけ討つ）
  - 自分たちの兵糧が先に尽きるなら、残りが10日を切るか、離れて5日たった時に、もう一度斬り込む。斬り込んだ部隊は敵将の隣を目指し、隣の敵将（総大将を優先）に、毎日一騎討ちを申し込みながら攻め続ける
- 挑まれた側は戦況（兵力×士気の比、残り日数、城門の有無、兵糧）で判断する。負けそうなら一発逆転を狙って受け、このまま勝てそうなら「勝ち戦で付き合う義理はない」と断る。豪傑同士（武力85以上どうし）と猪突はほぼ必ず受ける。剛勇は受けやすく、臆病・慎重は避けやすい
- 弱い武将（武力65未満、または挑んだ相手より武力が15以上低い）は基本的に受けない（猪突だけはまれに無謀に受ける）。挑む側も、弱い相手には時々しか挑まず、武勇の将は受けて立ちそうな手応えのある敵将を探して近づく
- 天下無双（呂布、武力98以上）は誰の挑戦でもすべて受けて立つ
- 君主は負ければ命を落としかねないので、武力で10以上勝る相手でなければ受けない（「一国の主が、匹夫の勇を競うわけにはいかぬ」）。自分から挑むのも10以上勝る相手だけ
- 総大将は基本的に受けない（軍師が止める）。ただし明らかにジリ貧のときは「この一戦に賭ける！」と受けることがある（剛勇・猪突の総大将は早めに賭けに出る）
- 全国の采配：軍師の能力で季節ごとの計略の回数が変わる（高い2回・中1回・低いと気まぐれに1回。智謀・神算なら+1）。出陣しない武将のうち知力の高い者が実行役。忠誠の低い敵将には引き抜き、野心家や不満のある敵将には離間、これから攻める都市には流言で下ごしらえ
- 戦場：移動の前にも後にも一騎討ちの好機を探す。剛勇・猪突は格上にも挑み、臆病・慎重は大差がないと挑まない。敵の総大将を討てそうなら積極的に挑む（賢い軍師ほど）。知力の高い武将（智謀・神算は65以上）は火計・混乱を使い、森の敵には火、雨や総大将には混乱

**武将の配置換え（強い武将は前線へ）**
- 季節ごとに、内地にいる強い武将（統率＋武力がおおむね150以上で、武の方が得意な者）を前線へ移す。内地には内政の得意な武将を1人残し、君主は動かさない
- 送り先の優先：兵を集めている攻撃の拠点 → 攻める予定の都市 → 敵の圧力が強い前線。武将が多い前線は後回し
- 知力の高い軍師は、前線に武将が多すぎる都市から文官を内地へ戻して内政を任せる。知力の低い軍師は送り先が大ざっぱ
- コンピュータ勢力も、季節に1〜2人、後方の強い武将を前線へ移す
- 戦場では、武力85以上の武将（特に剛勇・猪突）は前に出て敵とぶつかる

**在野の人物の登用（放っておかない）**
- 登用を内政より先に行う（以前は内政で武将が出払い、登用の順番が来ても誰も動けなかった）
- 自領で見つけた在野の人物は、価値の高い順に、その都市にいる魅力の高い武将が誘う
- その都市に動ける武将がいない、または他の都市にずっと魅力の高い武将がいるときは、その武将を向かわせて次の季節に誘う（断られた相手ほど、より魅力の高い使者を送る）
- 断られても、季節ごとに誘い続ける
- 諸葛亮は君主自身がその都市へ出向いて3度訪ねる（三顧の礼）
- 見つかっていない人物がいる都市では、探索の優先度を上げる

**猛将の出陣願い**
- 強くて頭の良くない武将（武力85以上で知力60以下、または武力80以上の猪突）は、守りの兵を残しても自分の上限いっぱいの兵を率いられるようになると、自分から出陣を願い出る（張飛「兄者！ 兵は揃った、俺に行かせてくれ！」）
- 攻め先は本人の見立てで、勝ち目が五分程度（0.95倍。知力が低いほど甘く見る）あれば攻め込む。軍師の慎重な見積もりは通さない。同じ城の待機武将を最大2人連れていく
- 知力の高い軍師は、あまりに分が悪いとき（0.8倍未満）だけ止める。止められた猛将は忠誠 -3
- 君主が猛将（呂布・孟獲など）の場合は、願い出ずに自分の判断で出陣する（呂布「兵は揃った。俺が出る。誰も止めるな」）。軍師は止められず、見送りの言葉をかけるだけ。君主が討たれたり捕まったりすると、跡継ぎに代わる
- 同じ都市からほかの部隊が出陣していても、その兵を差し引いて上限まで率いられるなら出陣する
- 1季節に最大2件。コンピュータ勢力も、猛将（君主を含む）の兵が揃っている都市は攻める基準が下がり（1.0倍）、見送りもしない。猛将の君主は本拠を空けてでも自ら出る

**内地で鍛えて前線へ**
- 敵に接していない内地の都市は、訓練を多めに行い、兵も集める（兵の訓練場・補給庫の役目）
- 訓練が進んだ内地の兵は、攻撃の拠点や、兵が敵の脅威に足りない前線の都市へ送り出す（訓練の値も一緒に引き継がれる）

**降伏勧告**
- 見込みは、兵力差・都市の数・囲まれ方（相手の都市の隣を、こちらと同盟国がどれだけ占めているか）・最後の一城か・兵が残っているか・敵意・使者の魅力で決まる。国境を接していない相手はまず降伏しない（最大10%）。囲みが甘いうちは上限が下がる（上限＝35%＋囲み×60%）。都市が多い国ほど粘る
- 骨のある君主もいる：野心（上限50%）、剛勇・猪突（上限60%）、忠義は降伏しにくい。曹操・劉備・孫権・孫策と武力95以上の君主は、どれだけ追い詰めても見込みは30%まで。臆病・慎重は降伏しやすい
- 相手を選ぶ画面に「見込み 高／中／低／なし」を表示（いちばん魅力の高い使者を立てた場合）
- 軍師オート：知力の高い軍師は見込み20%以上の相手に、ふつうの軍師は30%以上（15%以上なら時々）の相手に、毎季勧める。知力の低い軍師は見境なく勧めることがある。降伏した都市への出陣は取りやめる
- コンピュータ勢力どうしでも、追い詰めた隣国（プレイヤー以外）を降伏させることがある

**合従（敵どうしの同盟）**
- プレイヤーの都市が8以上で、ある勢力の1.5倍以上になると、その勢力はプレイヤーと接する別の勢力（自分とも接している、いちばん強い所）と手を結ぶことがある（季節ごとに15%）。同盟した勢力どうしは攻め合わず、合戦では援軍を送り合う
- 「天下の動き」として知らせる。例：孫権「曹操の勢いは、もはや捨て置けぬ。劉備殿、ここは手を携えよう」

**同盟の決まり**
- 接している敵勢力のうち、必ず1つは同盟せずに残す（攻める相手がいなくならないように）。他勢力からの同盟の申し出も、受けると全員が同盟相手になる場合は断る

**城の守り（戦場）**
- 序盤の調整：城壁と援軍の効き目は、攻める側の勢力の大きさで変わる（都市3以下で35%、12以上で100%）。小さな勢力のうちは城を落としやすく、大きくなると今の強さになる。城門の耐久は「400＋城壁×（3＋6×効き目）」
- 城門の耐久は「600＋城壁×9」
- 城内・城門・本丸にいる守り手は、受ける被害が「1＋城壁÷750×序盤の効き目」分の1になる（城門が破れると効果は半分）
- 門が無事なうちは、城内の守り手は城壁の上から2マス先の敵まで矢を射られる（威力も城壁に応じて上がる）。守り手は全員城内に構え、よほど優勢でなければ打って出ず、城壁に拠って戦う。城門の上に立って門を守ることもある
- 試算（攻め手が守り手の1.5〜2.5倍の兵、両軍AI、各50戦）：守り手の勝率は約1割から約4割に上がり、合戦は平均8日から約13日に延びた

**攻めの総大将の動き（コンピュータが動かすとき）**
- 味方が残っているうちは、味方のいちばん後ろ（城から最も遠い列の1つ後ろ）につき、敵に隣り合う場所を避ける。攻撃は最後の番手として、兵が自分の6割未満の弱った敵か、隣に迫られたときだけ
- 戦況が悪い（見通し−0.2未満）か、兵が半分を割ったら、敵から離れる方向へ一時的に下がる
- 最後の1部隊になったら、改めて自ら攻めに向かう。本丸に入れるときは迷わず入る
- 試算（攻め手が守り手の2倍、両軍AI、各150戦）：攻めの総大将が討たれて負けたのは、序盤 22回→2回、後半 36回→5回。守り手の勝率は後半 42%→29%、序盤 25%→27%

**大軍の攻め**
- 武将1人が率いられる兵は「2500＋統率×90」（統率80で約1万、5人で4〜5万）。以前は「1500＋統率×60」で、5人でも3万ほどにしかならず、何十万の兵がいても強い城には攻め込めなかった
- 攻め先の選び方：勝ち目（力の比）と人口に加えて、戦略上の値打ちを見る。最後の一城（勢力を滅ぼせる）+0.8、敵の本拠+0.3、すでに自分の都市に囲まれている所（隣の自都市1つにつき+0.1）は高く、取ったあと別の敵の大軍の矢面に立つ所は低く（最大−0.5）。知力の高い軍師はこれを重く見て、ふつうの軍師は半分、低い軍師は見ない
- 出陣の前に、忠誠40未満の将（寝返りのおそれ）には褒美を与えて引き締め、それでも足りなければ留守番にする（知力の低い軍師は気づかない）
- 計略は、次に攻める都市（今季攻めて落とせなかった所や、兵を集めている攻め先）の将を優先して崩す（知力の高い軍師ほど重く見る）
- 内政で手の空いた将には修行をさせる（武の将は統率・武力、文の将は政治・知力の低い方。知力の高い軍師は必ず、ふつうの軍師は半分。低い軍師はしない）
- 弱小勢力の立ち回り（都市3以下、または隣のいちばん強い勢力の6割に満たない力のとき。ふつう以上の軍師）
  - 外交：自分より強い隣国と、毎季節85%で同盟を申し込み、背後を固める（攻める相手か空き城が残る場合だけ）
  - 攻め先：空き城（+0.5）と、前の季節から兵が3割以上減った城（他と戦って消耗した隙、+0.5）を狙い、自分の2倍以上の力がある勢力の城には手を出さない（−0.4）。知力の高い軍師はこれを強く、ふつうの軍師は6割で見る
  - 内政：前線の徴兵を1.25倍、強い隣国に脅かされている城の修築を1.3倍に重く見る
  - 季節の初めに軍師が「今は小国。強国とは争わず、空き城と隙を狙います」と方針を言う
  - 試算（弱小4勢力×8季節：194年劉備・190年孫堅・194年孫策・208年劉備）：増えた都市の合計 13→22、敵に攻め込まれた回数 14→5、出陣の勝敗 18勝4敗→17勝5敗
- 中盤・終盤の立ち回り（ふつう以上の軍師）
  - 主敵：接している勢力のうち、いちばん倒しやすい所（力が小さく、こちらと接する城が多い）を主敵とし、その城を少し優先して攻める（知力の高い軍師+0.2、ふつう+0.1）。主敵とは同盟しない。季節の初めに「まずは○○軍を討ち、敵を一つずつ減らします」と方針を言う
  - 終盤：最後の一城・本拠の値打ちを1.5倍に見て勢力ごと崩す。後方の都市は兵3万から前線へ送る
  - 猛将の出陣願い：軍師が止める基準を、軍師の優秀さに合わせた（知力の高い軍師は求める勝ち目の85%未満、ふつうの軍師は70%未満で止める。以前は知力の高い軍師だけが、勝ち目0.8未満で止めていた）
  - 試した案：主敵以外の強国と同盟して二正面を避ける案は、降伏勧告で吸収できたはずの勢力まで同盟相手にしてしまい、成績が下がったので取りやめた
  - 試算（中盤・終盤の4勢力×8季節を2回ずつ：200年曹操・208年曹操・200年袁紹・208年孫権）：増えた都市の合計 52→57、出陣の勝率 約60%→約64%。回ごとの振れ幅が大きく、はっきりした差ではない
- より強く、より戦って勝つために（賢くしすぎて戦わなくならないよう）
  - 出陣では、守備兵を残したうえで出せる兵をすべて連れていく（以前は勝つのに要る分＋少しだけ）。兵が多いほど勝ち目は上がり、生き残った兵は戻ってくる。周りの都市から合流させる兵も、勝ち目に余裕が出るくらい（必要な分の1.3倍）まで集める
  - 出陣しない季節が続くと、勝ち目の基準を1季節ごとに5%ずつ下げる（最大20%）。出陣できたら元に戻る
  - 攻めの拠点（兵を集めている都市）では訓練を1.5倍、徴兵を1.3倍に重く見て、強い軍を作ってから攻める
  - 試算（194年曹操・194年劉備・200年曹操・208年孫権×8季節）：出陣 30→32回、勝敗 16勝14敗→23勝9敗、増えた都市の合計 15→23。さらに勝ち目の基準を下げると、出陣28回・23勝5敗・増えた都市の合計33（下げる前の同じ条件では32回・20勝12敗・12）
- 万能型の軍師：知力・政治ともに90以上の者（曹操・荀彧・司馬懿・魯粛・諸葛亮）。富国強兵の独自の采配をする
  - 内地は開墾・商業1.2倍、訓練1.15倍。前線は徴兵1.2倍、訓練1.25倍、修築1.1倍。内地には内政型と同じく文官を置く
  - 求める勝ち目は知力の段階の0.95倍、同時に攻める数は+1。守備兵は隣の敵の55%以上を残す
  - 計略は1回多く、外交もいつも行う。褒美の目安は忠誠65。手の空いた将には必ず修行
  - 季節の初めに「富国強兵。内を固め、外を討ちます」と方針を言う。「軍師を替える」の一覧に「万能型」と出る
  - 試算（8季節）：200年曹操で荀彧（万能）と郭嘉（戦）は、都市 19と11、出陣 13回8勝と9回2勝、兵 23.9万と16.9万、商業 8248と5056。194年曹操で荀彧と荀攸（戦）は、都市 13と12、出陣 10回5勝と9回8勝
- 内政型の軍師：治世を持ち、政治85以上で知力以上に政治が高い者（智謀・神算の者と君主、万能型は除く。鍾繇・陳羣・華歆・張昭・張紘・顧雍・糜竺・馬良・蒋琬・費禕・劉巴）。自動で軍師を選ぶときは知力が近ければ戦の軍師を優先し、内政型は「軍師を替える」で選ぶ（一覧に「内政型」と出る）
  - 戦は控えめ：求める勝ち目を1.25倍にし、消耗戦はしない。出陣は1季節に1つまで。攻めない季節が続いても焦らない
  - 前線：隣の敵のいちばん兵の多い都市と同じくらいの兵を置く（輸送・徴兵で揃える）
  - 内地：人口15万人ごとに1人（1〜3人）の文官を置き、足りなければ文官の多い都市から呼ぶ
  - 内政：開墾・商業1.25倍、修築1.2倍、訓練1.3倍、人材探し1.2倍に重く見る。手の空いた将には必ず修行をさせる
  - 試算（8季節）：194年曹操 荀彧（内政）と荀攸（戦）で、出陣 7回と10回、兵 15.1万と13.6万、商業 6318と4922、民忠 65と58。208年孫権 張昭（内政）と自動で選ばれた軍師で、出陣 5回と8回、兵 23.2万と12.5万
- 1季節の順番：①軍師が今季の方針を話す → ②褒美 → ③出陣（将・兵・兵糧を寄せてから攻める） → ④外交（同盟・降伏勧告） → ⑤計略 → ⑥武将の配置換え・人材探し・登用 → ⑦内政 → ⑧兵糧・兵の輸送（後方の大軍を前線へ送るのもここ）。出陣を最初にしたので、攻めに使う武将が内政で行動済みになることはない
- 局面の見立て：序盤（都市4以下で開始から3年未満）・終盤（天下の半分以上か都市16以上）・その間が中盤。武将が1都市あたり2人未満なら「人手不足」、4人以上なら「人材豊富」。季節の初めに軍師が一言添える
- 局面ごとの内政の重み（民忠40未満の施し・前線の兵不足の徴兵など「最優先」の項目にはかけない。知力の低い軍師ほど重みが弱まる）

- 兵5万以上の都市は、基本的に毎季節攻め込む（隣で一番落としやすい敵都市へ。勝ち目が薄くても行く）。率いる武将が足りなければ地続きの都市から呼び（各都市に1人は残す）、兵糧が20日分に足りなければ地続きの都市から集める
- 敵と接していない都市に兵3万以上（内政型は4万以上）がいれば、季節の終わりに、地続きで一番近い前線の都市へ兵を送る（8000か必要な守備兵を残す）。次の季節にそこから攻め込む
- 兵2万以上いて出陣しなかった都市があれば、ほかの都市から出陣した季節でも、いちばん兵の多いその都市について軍師が理由を言う（後方なので前線へ送る／隣が同盟国ばかり／率いる将がいない／将が少なく率いられる兵の上限で足りない／隣の大軍に備える守備兵と、いちばん取りやすい攻め先の勝ち目）。出陣の直前に見送るとき（兵糧が足りない・将がほかの出陣に回った）も理由を言う
- 兵が揃ったら必ず攻める：都市の兵（守備兵を残した分）が、出陣できる将の率いられる最大の数に達したら、勝ち目に関係なく必ず一番取りやすい隣の敵都市へ攻め込む（「勝ち負けは天に任せ、○○へ攻め込みます」）。将が足りなければ地続きの都市から呼ぶが、出陣する都市にも呼ばれる都市にも、必ず1人は将を残す
- 武将のいない城を作らない：季節の最後に、武将のいない自分の都市があれば、将が2人以上いる近い都市から1人回す（前線には統率の高い将、内地にはそれ以外）
- 将が足りない時：率いる将が3人未満で、君主が戦える（統率＋武力140以上）なら、君主も軍に加わる。兵2万以上の都市の将は、ほかの都市の出陣に回さない。兵の多い前線の都市で将が足りなければ、将に余裕のある都市から武の将を回す（季節に3人まで）
- 軍師オートが1季節に攻める数は、知力に応じた数（1〜2）に、自分の都市8つごとに1を足す
- 包囲：5日目から、攻め手が守り手の1.8倍以上いれば、城内の守り手は毎日士気が下がり（最大−10）、兵が1〜4%ずつ逃げ出す。30日で落としきれなくても、守り手の兵は大きく削れる（消耗戦）
- 試算（後半、両軍AI、各50〜150戦）：守り手の勝率は、攻め手2倍で約28%、3倍で約4%。合戦は平均15〜17日
- 208年の曹操で4季節オート（2回）：出陣11回で8勝3敗（都市22→34）、出陣8回で2勝6敗（22→26）。振れ幅は大きい

**合戦のAI（攻撃の相手選びと立て直し）**
- 攻撃の相手は、この一撃で討ち取れる相手（とくに総大将）を最優先し、次に弱った相手を狙う。反撃で大きな損害を受ける相手は避け、武力で大きく勝る将の部隊は崩しやすいとみる
- 深手を負った部隊（守り手は兵が2割5分未満、攻め手は1割5分未満）は、味方が残っていれば敵から離れて立て直す。隣にとどめを刺せる敵がいればそれを討つ。城内の守り手は下がらず城壁に拠る
- 試算（攻め手2倍、両軍AI）：守り手の勝率は後半 約26%（120戦）、序盤 約20%（40戦）
- 知力の高い将（知力75以上か智謀・神算）の部隊は、門が無事なうちは、門を叩く1部隊でなければ城壁の上からの矢が届かない所で待つ（無駄に兵を減らさない）

**合戦の場面ごとの台詞**：兵が3割を切ったとき・敵部隊を壊滅させたとき・城門を破った／破られたとき・援軍が着いたとき（駆けつけた将と、助けられた総大将）・深手で下がるときに、性格ごとの台詞を言う。張飛・関羽・呂布・趙雲・許褚・曹操・諸葛亮・黄忠には専用の台詞もある

**軍師の専用台詞**：諸葛亮・郭嘉・周瑜・司馬懿・龐統・陳宮・賈詡に加え、荀彧・荀攸・程昱・陸遜・魯粛・徐庶・法正・姜維・陳登・沮授・田豊・許攸・李儒・張昭・劉曄・呂蒙が、軍師として采配するときに人物らしい言い回しをする（7割の確率）

**敵襲の一言**：敵が攻めてきたとき、敵の総大将が性格に応じた一言を言う（董卓・袁紹・袁術・孫策・馬超は専用）。軍師の台詞（季節の初め・攻め・見送り・勝ち負け）も知力の段階ごとに増やした

**寝返り（戦場）**
- 3日目以降、忠誠40未満の武将（総大将・君主・忠義の武将は除く）が、敵に寝返ることがある（1つの合戦で1回まで）。見込みは（40−忠誠）÷250、野心なら+4%、自軍が苦しいと+5%、優勢なら−3%
- 寝返った部隊はその場で敵の部隊になり、裏切られた側の全部隊は士気−10。合戦が終わると、その武将は寝返った先の勢力に加わる（本拠へ移る。忠誠55〜75）
- 寝返りを防ぐには、出陣させる武将の忠誠を40以上に保つこと
- 内応の計（戦場の計略）：2マス以内の敵将に寝返りを誘う。プレイヤーは部隊の行動「内応」で、コンピュータ（敵も味方の軍師オートも）は知力の高い武将が、見込み25%以上の相手がいれば70%で使う。見込み＝0.05＋(60−相手の忠誠)÷90＋(知力の差)÷150＋(魅力−70)÷250、智謀・神算なら+8%、相手が野心家なら+8%、相手の軍が苦しければ+10%（2〜75%）。総大将・君主・忠義の武将、一度寝返った部隊には効かない

**逆転の目（戦場）**
- 援軍：開戦時に、どこから・何日目に来るかが決まる。率いるのはその都市のいちばん強い武将（君主は除く）で、兵は都市の35%（2000〜9000、統率による上限あり、都市には1500残す）。騎馬の将なら1日早い。生き残りは元の都市へ帰る
  - 守る側・隣の自都市（兵4000以上）：85%で来る。3〜7日目
  - 守る側・同盟国（隣に兵5000以上の都市があり、攻め手と同盟していない国）：55%（君主が忠義・仁徳なら75%、野心なら40%）。4〜9日目。同盟国の部隊は自分たちで動く
  - 攻める側・隣の自都市（兵6000以上）：45%。5〜11日目
  - 急報：守り手が苦しい（戦況が悪い、または城門が破れた）と、まだ着いていない援軍が毎日50%で急いで到着する
  - 苦しい側に届いた援軍は全軍の士気を+15し、総大将が「助かった！」と叫ぶ。守りの援軍は攻め手の側面・背後に現れる
- 市民兵：守りの総大将の魅力が78以上、都市の民忠が75以上のとき、城門が破れるか戦況が苦しくなると、民が立ち上がることがある（1回まで。見込みは魅力・民忠が高いほど上がる）。兵は人口の1/80（1000〜5000）。守り切ると、生き残りの半分が兵に志願する
- 背水の陣：兵が相手の4割を切った側が一度だけ奮い立ち、3日間攻撃力1.3倍・士気+30
- 包囲：門の外（野戦）で、上下左右の2部隊以上に囲まれた部隊は、囲む側から受ける被害が増える（囲む部隊が1つ増えるごとに+12%、知略の将〔知力75以上か智謀・神算〕が加わると1人につき+10%。囲まれたのが猛将〔武力85以上〕なら知略の将1人につきさらに+10%、囲む側の兵が少なければ+10%。夜戦ではこの上乗せが1.3倍）。囲まれた部隊は毎朝士気が下がり（囲む部隊が1つ増えるごとに−4、知略の将1人につき−3、夜戦は1.5倍）、3部隊以上に囲まれると反撃も弱まる（×0.85）。城壁の内側（城内・城門）の部隊は囲まれても崩れない。部隊を動かす判断でも、味方が隣にいる野戦の敵を横から囲みにいく（知略の将ほど）
- 統率の効果（戦場）
  - 守りの補正：統率85以上の将だけ。高いほど尖って効き、受ける被害が 統率85で約0.2%・90で約3%・95で約7%・100で約13%（÷1.15）減る
  - 鉄壁の采配：守りの名手5人（曹仁〔樊城〕・郝昭〔陳倉〕・満寵〔合肥〕・陸遜〔夷陵・石亭〕・司馬懿〔北伐を防ぐ〕）の隣にいる味方は、受ける被害が15%減る
  - 名将の采配：統率85以上の将は、毎朝、自分と隣の味方の士気を立て直す（＋(統率−80)÷3、統率100で＋7）。統率85以上の将の部隊は士気が落ちても崩れにくい（士気12未満ではなく9未満で退却）
  - 兵の回復：統率の上位者（名将、全武将の上位5人）は、毎朝、傷ついた兵を戦列に戻す。1日に最大の兵の（統率−70）÷1400（統率98で2%、天下一の名将は1.3倍）。本拠の城を守る時は2倍
  - 試算（攻め手が2倍の兵、160戦）：守り手の勝率は約29%（統率の効果を入れる前は約24%）
- 夜襲（守り手の計）：守り手に知略の将（知力75以上か智謀・神算）がいれば、2日目以降、闇に紛れて城を出て攻め手の陣を襲い、夜明け前に城へ引き上げる。確率は約5〜45%（知力が高いほど・智謀神算・攻め手が勝ちを確信して油断している・守り手が苦しいほど高い）。1つの合戦で2回まで、4日あける。夜襲に出るのは総大将以外の兵の多い順に最大3部隊（知略の将の隊は必ず）。狙うのは大部隊か総大将の陣（慎重な将の陣は避ける）で、その四方に忍び寄って次々に斬りかかる。寝込みを襲われた陣は反撃できず、士気−15、闇の中の不意打ちで兵がさらに2%（知略の将の隊は4%）減り、混乱することもある。周りの陣も浮き足立つ（士気−6）。その日は夜戦（画面が暗くなる）で、夜襲に出た部隊は疲れて動かない。攻め手の知力が高い・慎重・神算だと見破られて、待ち構えた矢で夜襲の部隊が痛手（兵−8%・士気−10）を負う。試算（攻め手が2倍の兵、160戦）：夜襲は41回、守り手の勝率は約24〜29%で、大きくは変わらない
- 守り手の城外の布陣：守り手が3部隊以上のとき、総大将・君主以外の部隊を城外に置ける。プレイヤーが自ら守る合戦では、開戦時に部隊ごとに「城内に構える／森に伏兵／山に陣取る／川辺で待ち構える」を選ぶ（その地形がない時は選べない）。コンピュータ（と委任・観戦）は、守り手の部隊数の半分（攻め手が4部隊以上ならさらに1つ）を、将に向いた所へ出す（知力→森、統率→山、武力・弓術・水軍→川辺）。部隊の多い同士の戦いほど城外の戦いが増える。城外の部隊は陣を動かず届く敵を討ち、門が破れるか守り手が優勢になると打って出る
  - 森の伏兵：攻め手からは見えない（プレイヤーが守り手なら半透明で見える）。敵が隣に来た瞬間に奇襲し、その部隊の兵の（5%＋知力×0.22%、智謀・神算は＋4%）を討つ（知力90で約25%、ただし伏兵の兵の6割まで）。士気−15、その部隊の行動はそこで終わり、知力80以上なら混乱させることもある
  - 山に陣取る：山の守りの効果（被害÷1.35）に加えて、さらに被害÷1.3
  - 渡河中の敵：川・浅瀬にいる部隊を岸から攻めると被害1.35倍、川辺で待ち構えた部隊なら1.7倍（両軍とも）
  - 部隊の多い同士（両軍4部隊以上）の戦いでは、城内の守り手も少し優勢なだけで打って出る
  - 試算（攻め手が2倍の兵）：守り手の勝率 約20〜26%→約29%、合戦の平均日数 約13日→約16日（城外の戦いが増えた）
- 夜戦への吊り出し：攻め手が劣勢で逃げ腰になったとき（3日目以降、見通しが悪いか兵が守り手の9割未満）、攻め手に知略の将がいれば、偽って退いて守り手の猛将や総大将（猪突・剛勇ほどかかりやすく、慎重・知力の高い将はかかりにくい）を夜戦におびき出す。確率は約30%〜70%（知力が高いほど・智謀神算・相手がかかりやすいほど高い）。1つの合戦で2回まで、4日あける。相手の知力が高い・慎重・神算だと見破られる。成功すると、おびき出された部隊は門の外の攻め手のそばに出て、その日は動けず（士気−15）、近くの攻め手の部隊が四方から伏兵として取り囲み、すぐに奇襲（1部隊につき兵の7%、知略の将の隊はさらに3%）。その日は夜戦：画面が暗くなり、矢の威力は0.6倍、知略の将の計略は成功率+20%（知力の低い猛将が相手ならさらに+10%）、包囲の上乗せ1.3倍。翌朝に夜が明ける。試算（郭嘉を連れた攻め手16,000で、張飛のいる守り手20,000の城を攻める）：前は30戦0勝→今は30戦5勝、おびき出された将が討たれたのは29回中9回
- 結果だけの委任（自動戦闘）も、力の見積もりの振れ幅を広げて番狂わせが起きるようにした。城壁の効果を強め（1.15＋城壁÷1500倍）、隣の自都市・同盟国からの援軍も兵力に加わる（7割の働き、援軍にも損害が出る）

**兵糧と補給**
- どの軍師も、次の秋の収穫までに兵が食べる分＋予備（前線は多め）を都市に残す（`Game.foodReserve()`）
- 出陣で持ち出す兵糧・施し・徴兵は、その予備を割り込まない範囲でだけ行う。足りなければ出陣を見送る
- 兵糧・金・兵が足りない拠点には、自領を通って行ける余裕のある都市から輸送する（`doLogistics()`）。前線を優先し、前の季節に受け取った相手へ送り返す往復はしない
- 知力の低い軍師は、兵糧が予備を割った所にしか気づかない。高い軍師は金・兵まで含めて前もって融通する
- 委任した都市（とコンピュータ勢力）の内政も、施し・徴兵で兵糧の予備を割り込まない

軍師の判断は `js/auto.js` の `brain()`（能力と癖）、`needs()`（内政の優先度）、`planAttacks()`（攻め時）にある。

## 調整するときに触る場所

- `CONFIG`（`js/game.js`）— 内政の金額・兵の上限・同盟期間・戦場の日数
- `Game.doCommand()` — 内政の効果量
- `AI.considerAttack()` — AI が攻めてくる基準（`aggressive` を下げると好戦的に）
- `Battle` の `calcDamage()` — 戦場のダメージ式。`DEFK` は地形の防御効果
- `js/lines.js` — 台詞。`LINES`（性格ごと）、`SPECIAL_LINES`（人物ごと）、`VOICE`（一人称と主君の呼び方）。`{I}` `{you}` `{lord}` `{foe}` は自動で置き換わる
- 武将を足すときは `GENERAL_SRC` に1行足す（書式はファイル先頭のコメント）

## セーブ

- localStorage `internT_gunyu_save_v1`。季節の終わりに自動保存される
- 自動セーブとは別に、任意に保存できる記録の枠が5つある（`internT_gunyu_save_v1_slot1`〜`slot5`）。メニューの「セーブ」で枠を選んで保存し、使っている枠は上書きしてよいか確かめる。自動セーブでは書き換わらない
- ロード（メニュー、タイトルの「続きから」）は、自動セーブと記録1〜5から選ぶ。各枠に勢力・君主・年と季節・都市の数・保存した日時を出す（見出しは `…_info` に別に持つ。古い自動セーブは中身から見出しを作る）
- ゲームが終わると自動セーブだけ消え、記録の枠は残る
- 記録の枠は消せる：セーブ・ロードの一覧の下の「記録を消す」から枠を選び、確かめてから消す（元に戻せない）。自動セーブは消せない
- 音のオン・オフは `internT_mute`
